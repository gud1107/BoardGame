# 달무티 — "계급 서사" 32스텝 프로시저럴 BGM (Dalmuti Class-Saga BGM)

- 작성일: 2026-09-28
- 상태: **구현 완료 — 커밋/푸시 완료(운영 배포는 GitHub 웹훅 자동)**
- 대상 게임: `src/games/dalmuti/` (id `dalmuti`)
- 선행 문서: [dalmuti-court-bgm-spec.md](./dalmuti-court-bgm-spec.md) (2026-09-27 검토본). 그 문서 §5의 결정 1번("신디 BGM으로 mp3 슬롯 대체")을 이번 요청으로 확정해 구현했다. SFX 관련 항목(2~3번)은 이번 요청 범위 밖이라 그대로 남아 있다.

## 1. 요청 요약

"인생의 불공평함과 계급 투쟁, 궁정 연회의 화려함과 선술집의 익살"을 살린 BGM을 오디오 파일 없이 Web Audio API로 만든다. 1마디 반복 대신 네 계급을 차례로 거치는 8마디(32스텝) 진행을 쓴다.

| 파트 | 마디 | 계급 | 화성 | 성격 |
|---|---|---|---|---|
| A | 1–2 | 농노의 노동요 | Am | 투박한 류트 단음 + 드론 |
| B | 3–4 | 선술집·상인 | C → F | 밝아지고 탬버린이 고조 |
| C | 5–6 | 귀족·기사단 | Dm → G | 도약하는 류트 아르페지오 |
| D | 7–8 | 달무티의 왕좌 & 혁명의 전조 | E7 (G# 반음 긴장) | 다음 루프 첫 박 Am으로 해결 |

- 108 BPM, 8분음표 1스텝(≈0.278초), 한 바퀴 ≈ 8.9초
- 4개 레이어: 🪕 류트(triangle + lowpass 950Hz), 🎻 백파이프풍 드론(sawtooth + lowpass 260Hz), 🥁 탬버린, 🪈 궁정 피리 롱톤(파트 B·D 진입부)
- 볼륨: BGM 0.09

## 2. 구현 파일

| 파일 | 역할 |
|---|---|
| `audio/dalmutiScore.ts` | 순수 데이터 악보. `dalmutiEventsAt(step)`이 스텝마다 울릴 음 목록을 돌려준다. Web Audio가 없어서 테스트할 수 있다 |
| `audio/dalmutiScore.test.ts` | 템포·파트 구분, 드론 화성 진행(Am→C/F→Dm/G→E7→Am), 파트 D의 G#, 피리 위치, 연속 두 바퀴가 같지 않음 — 5건 |
| `audio/dalmutiSoundEngine.ts` | 신디사이저 싱글톤 `getDalmutiSound()`. 룩어헤드 스케줄러와 4개 음색 |
| `DalmutiBoard.tsx` | 보드 마운트 동안 BGM 재생(`setBgmWanted`), 기존 첫 터치 언락·`dispatch`·🔊 버튼에서 이 엔진도 언락, 상단 버튼 줄에 🪕 BGM 토글 추가 |
| `DalmutiGame.tsx` | 파일이 없어 무음이던 `useGameBgm("dalmuti")`(mp3) 호출 제거 |

명세 경로대로 `audio/` 하위 폴더에 두었다(코요테·랫어탯캣은 게임 폴더 바로 아래에 둠).

## 3. 명세와 다르게 한 부분 (의도적)

1. **"비반복 변주"를 실제로 넣었다.** 명세 제목은 "프로시저럴 모달 변주"였지만 코드는 32스텝 한 바퀴를 똑같이 반복했다. 이번 악보는 바퀴 번호(`cycle`, 0~3)로 변주를 고른다. 결정론적이라 테스트할 수 있다.
   - 0바퀴: 명세 선율 그대로
   - 1바퀴: 파트 B·C의 쉼표를 경과음으로 채우고, 파트 C 류트를 한 옥타브 위로(귀족의 과시)
   - 2바퀴: 파트 A를 드문드문한 류트만 남기고 탬버린을 뺌(숨 고르기). 파트 B 진입 피리를 C5 대신 D5로
   - 3바퀴: 파트 D 류트에 6도 아래 화음을 겹치고, 파트 A에서도 탬버린이 매 스텝 울림(혁명 전의 가장 빽빽한 바퀴)
2. **탬버린에 노이즈를 더하고 파트 A에서는 절반만 친다.** 명세의 탬버린은 2.6~3.2kHz 사인파 비프를 매 8분음표 울렸다(선행 검토본 §3-4에서 지적). 명세의 비프는 그대로 두고 6kHz 이상 짧은 노이즈 "찰랑"을 섞었다. 농노 파트(A)는 정박에만 친다.
3. **음소거·볼륨은 사이트 공용 설정을 따른다.** 명세의 자체 `isMuted`/`toggleMute` 대신 `audioSettings.ts`를 쓴다. 기본 BGM 슬라이더(0.4)일 때 명세 볼륨 0.09가 나오도록 맞췄다.
4. **🪕 BGM 토글 버튼을 추가했다.** 사이트 기본값이 BGM 음소거라서, 기존 🔊(마스터) 버튼만으로는 BGM이 켜지지 않는다. 버튼을 켜면 마스터 음소거도 같이 풀린다(코요테·랫어탯캣 HUD와 같은 동작).
5. **스케줄러는 `setInterval` 룩어헤드 방식이다.** 명세의 `setTimeout` 재귀는 탭이 스로틀링된 뒤 돌아오면 밀린 음을 한꺼번에 친다. 이 방식은 현재 박자에 다시 합류한다.
6. **재생 시작·정지는 보드 마운트/언마운트에 묶었다.** 명세에는 `stopBGM()` 호출 지점이 없었다. `DalmutiBoard`는 `phase === "playing"`일 때만 렌더되므로 기존 mp3 규칙("실제 대국 중에만")과 같다.
7. **SFX는 만들지 않았다.** 명세 엔진에 `sfxGain`이 있었지만 SFX 함수는 없다. 카드 제출·패스·대혁명 소리는 기존 `soundEngine.ts` 그대로다.

## 4. 검증

- `npx vitest run src/games/dalmuti` — 2개 파일 80건 통과(신규 악보 테스트 5건 포함)
- `npx eslint src/games/dalmuti` — 경고/오류 없음
- `npx tsc --noEmit` — 이번 변경 관련 오류 없음. `.next/dev/types/validator.ts`가 다른 세션의 `zz-lot-preview` 페이지를 찾지 못하는 오래된 오류 1건만 있음
- 실제 소리는 헤드리스로 확인하지 않았다. 브라우저에서 달무티 방에 들어가 🪕 BGM을 켜고 들어봐야 한다.
