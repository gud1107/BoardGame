# 랫어탯캣 — 살금살금 피치카토 BGM & 카드 액션 SFX (Rat-a-Tat Cat Audio Suite)

- 작성일: 2026-09-27
- 상태: **구현 완료, 운영 배포됨**
- 대상 게임: `src/games/ratATatCat/` (id `rat-a-tat-cat`)

## 1. 요청 요약

톰과 제리풍의 "살금살금" 피치카토 재즈 BGM과 카드 액션 전용 효과음을, 외부 오디오 파일 없이 Web Audio API만으로 만든다. 게임 화면 상단에 사운드 토글 HUD를 둔다.

| 구성 | 내용 |
|---|---|
| BGM | 2/4박자, 112 BPM, D 단조 블루스. 16분음표 스텝 |
| 성부 | ① 피치카토 베이스 D2–F2–G2–G#2–A2 워킹 라인 ② 실로폰 엇박 멜로디 ③ 우드블록(쥐 발소리) ④ 4마디마다 한 번 울리는 고양이 챠임 |
| 볼륨 | BGM 0.1 / SFX 0.35 |
| SFX 6종 | 카드 드로우, Peek 휘슬, Swap 스우시, Draw 2 투톤 팝, 좋은 카드/나쁜 카드 피드백, "랫어탯캣!" 콜 경보 |
| HUD | 🐱 "Sneaky Cat" / 🔇 토글 |

## 2. 구현 파일

| 파일 | 역할 |

| `ratSneakScore.test.ts` | 악보 구조(템포, 챠임 빈도, 루프)와 신호 분류(드로우, 교체 품질, Swap/Draw 2 사용 vs 그냥 버리기, 콜) 테스트 9건 |

## 3. 명세와 다르게 한 부분 (의도적)

1. **음소거/볼륨은 사이트 공용 설정을 따른다.** 명세의 자체 `isMuted`/`toggleMute` 대신 `audioSettings.ts`를 쓴다. 헤더 🔇/🔊, 설정 모달 슬라이더, 게임 HUD가 항상 같은 상태를 보여준다. 기본 슬라이더 값(BGM 0.4 / SFX 0.7)일 때 명세 볼륨 0.1 / 0.35가 나오도록 레벨을 맞췄다.
2. **HUD는 BGM과 효과음 버튼 2개다.** 명세의 버튼은 첫 클릭에 BGM을 켜면서 동시에 음소거를 토글해서, 기본값에서 누르면 오히려 음소거가 되는 문제가 있었다.
3. **스케줄러는 `setInterval` 룩어헤드 방식이다.** 탭이 스로틀링된 뒤 돌아오면 밀린 음을 한꺼번에 몰아 치지 않고 현재 박자에 다시 합류한다.
4. **명세 스케치에 빠져 있던 성부를 채웠다.** 우드블록(각 마디 2박)과 고양이 챠임(4마디마다 G#5 한 번, D에 대한 트라이톤)은 설명에만 있고 스케줄에는 없었다. 실로폰은 한 프레이즈만 반복되던 것을 3–4마디의 하행 응답 프레이즈로 보강해 32스텝(4마디) 루프로 만들었다.
5. **콜 이후 긴장 모드를 추가했다(명세에 없음).** 누군가 "랫어탯캣!"을 외치면 다음 루프 시작부터 126 BPM으로 빨라지고, 챠임은 매 마디, 우드블록은 8분음표로 바뀐다.
6. **SFX는 버튼 핸들러가 아니라 상태 비교로 재생한다.** 봇과 상대 플레이어의 행동도 모든 클라이언트에서 들린다. 다만:
   - **Peek**는 사용과 그냥 버리기가 상태상 구분되지 않아서 본인이 Peek를 사용할 때만 재생한다. 상대나 봇의 Peek는 들리지 않는다.
   - **카드 품질 피드백**(0–2 고양이 방울, 8–9 쥐 "쿵")은 교체한 본인에게만 재생한다. 뒷면으로 들어간 카드 값을 다른 사람이 소리로 알 수 있으면 안 되기 때문이다. 3–7은 소리가 없다. 명세는 3 이상 모두 "쿵"이었다.
   - Swap과 Draw 2는 실제로 사용했을 때만 재생하고, 그냥 버렸을 때는 재생하지 않는다.
7. **카드 드로우 소리는 교체했다.** 보드에 있던 공용 `soundEngine`의 `playCardDrawWhoosh()` 호출을 새 카드 펄럭임 소리로 바꿨다. 두 소리가 겹치지 않게 하려는 것이다. `soundEngine.ts` 자체는 건드리지 않았다.
8. **콜 모달의 기존 사이렌은 유지했다.** `RatATatCatCallModal.tsx`의 `playRatCallSiren()`(사이렌 + 카운트다운 딩)은 그대로 두고, 새 콜 SFX(림샷 + 심장 쿵 + F#4–A4–C5 감3화음)를 그 앞에 겹쳐 친다.
