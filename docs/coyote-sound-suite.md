# 코요테 — 스파게티 웨스턴 밴조 BGM & 블러핑 SFX (Coyote Sound Suite)

- 작성일: 2026-09-27
- 상태: **구현 완료 — 커밋/푸시 완료(운영 배포는 GitHub 웹훅 자동)**
- 대상 게임: `src/games/coyote/` (id `coyote`)

## 1. 요청 요약

엔니오 모리코네풍 황야 휘파람 + 2박자 밴조 스트럼 + 우드 탭으로 된 서부극 BGM과 코요테 전용 효과음을, 외부 오디오 파일 없이 Web Audio API만으로 만든다. 게임 화면 상단에 사운드 토글 HUD를 둔다.

| 구성 | 내용 |
|---|---|
| BGM | 4/4박자, 116 BPM, A 도리안(A 단조 웨스턴). 16분음표 스텝, 4마디(64스텝) 루프 |
| 성부 | ① 밴조 스트럼 A3–E4–A3–A4 / G3–D4–G3–G4 ② 휘파람 A4 C5 B4 A4 E5 D5 ③ 우드블록 말발굽 ④ 셰이커 ⑤ 방울뱀 꼬리 떨림 |
| 볼륨 | BGM 0.11 / SFX 0.38 |
| SFX 4종 | 숫자 선언 팝, "코요테!" 리볼버 장전 + 총성, 특수 카드 챠임, 하트 잃음 트롬본 |
| HUD | 🐺 "Western Coyote" / 🔔 효과음 토글 |

## 2. 구현 파일

| 파일 | 역할 |
|---|---|
| `coyoteWesternScore.ts` | 순수 데이터: BGM 악보(`westernEventsAt`)와 상태 스냅샷 비교 → SFX 신호 분류기(`coyoteSoundCues`). Web Audio가 없어서 테스트할 수 있다 |
| `coyoteWesternScore.test.ts` | 악보 구조(명세 선율 일치, 휘파람 음 겹침 없음, 타악 배치, 루프)와 신호 분류(선언, 코요테 콜, 다음 라운드와 무효 선언은 무음) 테스트 8건 |
| `coyoteSound.ts` | 신디사이저 싱글톤 `getCoyoteSound()`. BGM 스케줄러와 SFX |
| `CoyoteSoundHud.tsx` | 🐺 BGM / 🔔 효과음 토글 버튼 2개 |
| `CoyoteBoard.tsx` | 상태 비교 effect에서 선언/콜 신호 재생, `phase === "playing"` 동안 BGM 재생, 판정 연출 타임라인에 특수 카드 챠임과 하트 트롬본을 얹음, 첫 터치로 AudioContext 잠금 해제, 헤더의 📖 룰북 버튼 옆에 HUD 배치 |

구조는 랫어탯캣(`ratSound.ts`, `ratSneakScore.ts`, `RatSoundHud.tsx`)과 오이 다섯 개와 같다. 명세의 `audio/` 하위 폴더는 이 프로젝트 관례(게임 폴더에 하위 폴더 없음)에 맞춰 쓰지 않았다.

## 3. 명세와 다르게 한 부분 (의도적)

1. **"깃털 제거"는 "하트 잃음"이다.** 이 게임은 이미 깃털 대신 하트 2개로 바뀌어 있다(`engine.ts` 모듈 doc 가정 #5). 트롬본은 하트를 1개 잃을 때 울린다.
2. **음소거/볼륨은 사이트 공용 설정을 따른다.** 명세의 자체 `isMuted`/`toggleMute` 대신 `audioSettings.ts`를 쓴다. 헤더 🔇/🔊, 설정 모달 슬라이더, 게임 HUD가 항상 같은 상태를 보여준다. 기본 슬라이더 값(BGM 0.4 / SFX 0.7)일 때 명세 볼륨 0.11 / 0.38이 나오도록 레벨을 맞췄다.
3. **HUD는 BGM과 효과음 버튼 2개다.** 명세의 버튼은 첫 클릭에 BGM을 켜면서 동시에 음소거를 토글해서, 기본값에서 누르면 오히려 음소거가 되는 문제가 있었다.
4. **스케줄러는 `setInterval` 룩어헤드 방식이다.** 명세의 `setTimeout` 재귀는 탭이 스로틀링된 뒤 돌아오면 밀린 음을 한꺼번에 몰아 친다. 이 방식은 현재 박자에 다시 합류한다.
5. **악보를 4마디로 늘렸다.** 명세는 1마디(16스텝)를 무한 반복하고, 휘파람 음마다 3.5스텝씩 울려서 이웃 음과 겹쳤다. 이번 악보는 다음과 같다.
   - 1마디: 명세 선율 그대로
   - 2마디: 길게 끄는 E5(모리코네풍)
   - 3마디: B4–A4–G4–A4 하행 응답
   - 4마디: 휘파람 쉼
   - 음 길이는 음마다 따로 정해 겹치지 않는다(테스트로 확인).
   - 밴조는 4마디 뒷박에서 Em으로 바뀌어 루프가 마무리된다.
6. **타악을 둘로 나눴다.** 명세의 `playRattleTap`(삼각파를 1800Hz 하이패스에 통과)은 사실상 가는 클릭 소리였다. 설명에 나온 대로 우드블록 말발굽(2·4박, 850/600Hz)과 노이즈 셰이커(8분음표)로 나눴다. 루프 마지막 박에는 방울뱀 꼬리 떨림(노이즈를 28Hz로 끊음)을 한 번 넣었다.
7. **음색을 보강했다.**
   - 휘파람: 음 아래에서 끌어올리는 스쿱과 서서히 퍼지는 비브라토, 약한 숨소리
   - 밴조: 한 옥타브 위 트왱을 겹침
   - 트롬본: 음마다 "와" 필터가 열리고 마지막 음은 처지며 떨림
8. **"코요테!" 콜에 코요테 울음을 넣었다.** 명세의 "찰칵 + 탕"에 다음을 더했다.
   - 장전음을 두 번(찰-칵)
   - 노이즈 총성
   - 뒤이어 멀리서 들리는 "아우우~" 울음
   
   기존 `CoyoteHowlBanner`에는 소리가 전혀 없었다.
9. **숫자 선언 음높이가 호가에 따라 올라간다.** 명세의 320→540Hz 팝을 기준으로, 선언 숫자가 커질수록 최대 반 옥타브(40에서)까지 높아진다. 우드블록 노크도 겹친다.
10. **SFX는 버튼 핸들러가 아니라 상태 비교와 판정 타임라인으로 재생한다.** 봇과 상대 플레이어의 행동도 모든 클라이언트에서 들린다.
    - **선언/콜**: 연속 스냅샷 비교(`coyoteSoundCues`)로 재생한다. 무효 선언과 다음 라운드 시작은 무음이다.
    - **특수 카드 챠임**은 판정 연출 단계에 맞춰 울린다.
      - "?": 중앙 팝업이 뜨는 순간. 기존 `soundEngine`의 휙/카드 튕김 소리와 겹친다.
      - MAX→0: 슬래시가 시작될 때
      - x2 / 밤(0, 선 교체): 계산식이 나타날 때
    - **하트 트롬본**은 합계 카운트업이 끝난 직후(판정 순간) 울린다. 탈락(하트 0)일 때는 울리지 않는다. 기존의 흔들림 → 파쇄 → 해골 사운드 체인(`playDeathCardSting`/`playCardShatter`/`playEliminationSlam`)이 이미 있기 때문이다.
    - **⏩ 스킵**을 누르면 아직 남은 특수 카드 챠임은 생략하고, 하트 트롬본은 즉시 한 번 재생한다. 타이머가 나중에 다시 울리지 않게 막았다.
11. **BGM은 입찰 중에만 나온다.** `phase === "playing"` 동안 재생하고, 판정 연출 중에는 쉬었다가 다음 라운드에 처음부터 다시 시작한다. 게임 종료 화면에서도 멈춘다.
12. **기존 공용 효과음은 건드리지 않았다.** `soundEngine.ts`와 `CoyoteEffects.tsx`의 기존 호출은 그대로 두었다.

## 4. 검증

- `npx vitest run src/games/coyote`: 2개 파일, 76건 통과(신규 8건 포함)
- `npx eslint src/games/coyote`: 통과
- `npx tsc --noEmit`: 코요테 관련 오류 없음
- **실제 브라우저에서 소리를 듣는 확인은 하지 않았다.** 음색과 밸런스는 운영 배포 전에 직접 들어보고 조정할 항목이다.
