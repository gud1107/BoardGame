# 🐶 멍냥 방어선 (Pet Guard)

2~4인 · 약 15~20분 · 동시 진행 배치 전략 · 자체 창작 (코드 `src/games/petGuard/`, id `pet-guard`)

> 요청: "기물을 배치해서 나오는 물이 사람에게 가지 않게 하는 전략게임 / 벌이 나오는데 강아지를 지키는 게임" → "위험요소의 상황은 매우 다양하게 연출해서 개발".
> '배치한 뒤 물리 시뮬레이션을 지켜보는 방어 퍼즐' 장르만 빌려왔고, 특정 게임의 규칙·캐릭터·맵은 쓰지 않았다. 대전 요소(같은 재난 동시 진행 + 옆 사람에게 변수 보내기)는 이 사이트용으로 새로 만들었다.

## §1 목표
6라운드 동안 매번 들이닥치는 재난에서 내 펫(🐶🐱🐥🐹, 자리 순서)을 지킨다. 합계 점수가 가장 높은 사람이 우승.

## §2 라운드 구성
- 라운드마다 **모두가 같은 재난**을 각자의 12×14 판에서 맞는다. 판·예산·나오는 위치·무작위 요소(빗방울 열, 번개 열 등)도 모두 같다 — 차이는 배치와 받은 변수뿐.
- 1~2라운드 ⭐, 3~4라운드 ⭐⭐, 5~6라운드 ⭐⭐⭐ 재난에서 겹치지 않게 뽑는다.

## §3 설계 단계 (90초, 동시)
- 🪙 예산 안에서 기물을 놓는다. **펫 바로 옆 8칸·맨 윗줄·지형 위·위험이 나오는 칸**엔 못 놓는다. 같은 기물을 다시 누르면 치운다.
- 🔍 **시험 가동 3번**: 변수 없이 내 설계를 돌려 본다(실제 결과와 같은 시드).
- 🎴 받은 **변수 카드 3장 중 1장을 다음 자리**에 보낸다(앞자리 사람에게서 1장을 받음). 한 사람이 여러 장을 몰아 받는 일은 없다(킹메이킹 방지).
- 시간이 끝나면 지금 배치대로 자동 제출. 응답 없는 자리는 방장이 96초에 Lv.3 자동 배치로 채운다.
- 🚨 **재난 예보**(2026-11-24): 라운드 시작 때 3.2초 "재난 경보" 배너, 설계 화면에 위험마다 무엇이·어디서·언제(틱)·얼마나 + 틱 타임라인(`forecast.ts`). 판 위에는 물줄기·빗줄기·비행 경로(마리 수 배지)·무너질 둑이 움직이는 선으로 그려진다.

## §3-2 결과 · 다음 라운드 (2026-11-24)
- 리플레이에서 내 판이 끝나면 🛡️ CLEAR / 💥 FAIL 연출(빛살·색종이 / 금 간 화면·흔들림), 다른 판에는 작은 도장.
- ⏩ **스킵 투표**: 봇이 아닌 접속자의 절반 이상(1/1·1/2·2/3·2/4)이 누르면 모든 화면이 재생을 건너뛰고 결과표로. 다시 누르면 취소. 결정은 화면에서만 하고 엔진은 표만 셈(`skip` 액션).
- ✅ **자동 시작**: 결과표가 뜨고 6초 뒤(또는 "다음 라운드 준비" 버튼) 그 자리가 `ready`. 모든 자리가 준비되면 엔진이 바로 다음 라운드로 넘긴다. 봇·아무도 안 앉은 자리는 방장이 1.2초 뒤 대신 준비. 탭이 멈춘 사람이 있으면 방장이 결과 35초 뒤 `next`로 강제 진행.
- 게임 끝: 1위면 🏆 VICTORY!(빛살·색종이), 아니면 등수 배너.

## §4 시뮬레이션 규칙 (`sim.ts`, 정수 전용·결정론)
| 위험 | 움직임 | 상호작용 |
|---|---|---|
| 💧 물 | 아래 → 대각선 아래 → 옆 | 불을 끔, 생물을 빠뜨림, 용암과 만나면 흑요석+수증기, 번개를 맞으면 닿은 펫 감전 |
| 🌋 용암 | 물처럼, 3틱에 한 번 | 🪵·🌿·🌻에 불을 붙임 |
| 🧪 산성액 | 물처럼, 70틱 뒤 증발 | 🪵·🌻·🌿·선풍기를 1:1로 녹임 |
| 🏜️ 모래 / ❄️ 눈 | 떨어지고 대각선으로 미끄러져 쌓임 | 펫 머리 위에 얹히면 다침 |
| 🪨 바위 | 떨어짐, 옆이 비어야 굴러감 | 3칸 넘게 떨어지면 🪵·🌿·🌻를 부숨 |
| ☠️ 독가스 | 위로 오르고 옆으로 퍼짐(110틱) | 지붕 밑에 고임, 선풍기에 밀림 |
| 🔥 불 | 🪵·🌿·🌻를 태우며 상하좌우로 번짐 | 불똥이 한 칸 빈틈을 뛰어넘음(가운데가 단단하면 막힘), 물에 꺼짐 |
| 🐝 벌 | 최단 경로로 비행(상하좌우만, 대각선 틈 못 지남) | 🌻 꽃 하나에 4마리까지 붙음 |
| 🐝 말벌(빨간 테) | 벌과 같음 | 🪵를 10틱 동안 갉아 뚫음, 꽃 무시 |
| 🐀 쥐 | 바닥·벽에 붙어서만 이동, 떨어지기도 함 | 🪵를 갉음, 🌻에 끌림 |
| 🦇 박쥐 | 대각선으로 날며 벽에 튕김 | 길 찾기 안 함, 꽃 무시 |
| ☄️ 운석 | 대각선으로 낙하, 옆 벽에 튕김 | 부딪힌 곳 3×3의 약한 것을 날리고 5×5에 불똥 |
| ⚡ 번개 | 10틱 전 경고, 그 열의 가장 위를 때림 | 좌우 3칸 안 피뢰침이 대신 맞음, 🪵에 불 |

펫은 상하좌우에 물·용암·산성액·가스·불이 닿거나, 생물이 바로 옆(상하좌우)에 오거나, 머리 위에 모래·눈·바위가 얹히거나, 번개·운석에 맞으면 다친다.

## §8 점수와 튜닝 기록
- 버팀 = **10 + 남긴 🪙**, 다침 = **⌊7 × 버틴 틱 ÷ 전체 틱⌋** (0~6). 동점 → 버틴 라운드 수 → 쓴 🪙 적은 쪽.
- 셀프플레이(봇 Lv.3/6/10, 시나리오마다 4시드):
  - 처음엔 장맛비·산성비가 Lv.10도 0/4 → 원인은 액체가 **대각선 틈**으로 새는데 봇 시작 모양이 모서리를 비웠던 것 + 예산 부족. 비 양을 줄이고(121→81방울) 예산 7→9, 산성 빗방울 70틱 증발 + 예산 12. 산성비는 "돌 지붕 3 + 나무 모서리 2 + 양옆 배수구 2"(🪙12)가 모든 시드에서 버팀을 수작업으로 확인한 뒤 봇 시작 모양에 추가.
  - 산불은 처음에 빈 판도 버팀(불이 펫 옆 덤불까지 못 옴) → 불똥 한 칸 뛰어넘기 규칙 추가(확률 60%, 덤불 30틱).
  - 유성우·박쥐는 Lv.3도 쉽게 버팀 → 운석 9→13개, 박쥐 8→12마리. 말벌 여왕은 너무 어려워 펫 양옆에 바위를 두고 말벌 4→3.
  - 최종: 빈 판은 17개 중 17개 다침. Lv.10 평균 점수가 Lv.2보다 확실히 높음(`balance.sim.test.ts`).
- 알려진 한계: 락스텝이라 제출한 배치가 공개 전에도 네트워크 상태에는 있다(화면엔 숨김). 같은 재난이라 남의 배치를 베끼는 치트가 이론상 가능 — 변수 카드가 효과를 줄인다.
