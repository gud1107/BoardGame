# 인생 상황극 (Life Skit)

> 자체 창작 1~8인 동시 선택 콩트 게임. 공개 방송 콩트 쇼(SNL류)의 "상황극 한 꼭지" 형식만 빌렸고,
> 대본·배역·인물·규칙은 전부 이 프로젝트에서 새로 쓴 것이다(특정 프로그램의 코너·캐릭터·유행어를 옮기지 않는다).
> 구현: `src/games/lifeSkit/` · 게임 id `life-skit` · 패치 v1.180.0 (2026-11-17)

## §1. 한 줄 요약

각자 배역 하나를 골라 **7장면짜리 인생**을 동시에 산다. 장면마다 셋 중 하나를 고르는데, 보이는 건
"얻을 것 같은 것"뿐이다. 대가와 **성격 변화**는 공개 때 드러나고, 굳은 성격은 뒤 장면의 선택지를
바꾸고 🦋 나비효과로 돌아온다. 막이 내리면 인생 점수 + 받은 박수로 순위를 가린다.

## §2. 인원·시간

- 1~8명 (혼자서도 가능, 빈자리는 AI 봇 Lv.1~10)
- 7장면. 장면마다 고르는 시간: ♾️ 무제한 / 20초 / 30초(기본) / 45초 → 한 판 6~15분
- 락스텝(공유 시드 + 행동 재생). 숨길 정보가 없다 — 남의 선택은 공개 전까지 화면이 그리지 않을 뿐이다.

## §4. 수치

💰 재산 · ❤️ 관계 · 🌟 명예 · 😊 행복. 각각 0~12에서 멈춘다(넘치거나 모자란 만큼은 사라진다).

## §5. 한 장면

1. **고르기** — 상대역의 대사와 자막을 보고, 모두 동시에 세 선택지 중 하나를 고른다. 고르면 바꿀 수 없다.
   - 선택지에는 "얻을 듯" 힌트(오르는 수치의 종류)만 보인다. 양·대가·성격은 숨어 있다.
   - ⚡ **지름길**은 장면마다 정확히 하나. 눈앞의 이득이 크고 대가가 따라온다(늘 손해는 아니다).
   - 일부 선택지는 힌트가 실제와 다르다(함정).
2. **공개** — 결과 문장, 실제 수치 변화, 새 성격, 나비효과가 한꺼번에 드러난다.
   - 다른 사람의 장면 하나에 👏 박수(장면마다 한 번, 자기 자신 불가). 받은 사람 +2점.
   - 모두 ▶ 다음 장면을 누르면 넘어간다(제한 시간 방은 30초 뒤 자동).
3. 시간 초과면 아무 선택지나 대신 골라지고 "시간 초과" 표시가 붙는다.

## §6. 성격 (10가지)

📚 성실함 · 🦊 잔머리 · 🔥 배짱 · 🤑 욕심 · 🧭 정직함 · 🫶 다정함 · 🧊 무심함 · 🕊️ 자유로운 영혼 · ✍️ 글눈 · 🍭 오냐오냐

- 선택이 성격을 굳힌다. 한번 굳으면 끝까지 간다.
- **바뀌는 선택지(swap)**: 그 성격을 가진 사람에게는 뒤 장면의 선택지가 다른 것으로 바뀐다.
  예) 결혼기념일에 회사로 뛰어간 CEO(🧊 무심함)는 딸 생일 장면의 "비서에게 선물 배송을 맡긴다"가
  "…내일이 무슨 날이라고?"가 된다.
- **나비효과(echo)**: 그 성격으로 어떤 장면에 들어서면 무엇을 고르든 추가 결과가 붙는다.
  판정은 "그 장면에 들어올 때" 갖고 있던 성격으로 한다(그 장면에서 방금 얻은 성격은 다음 장면부터).

## §7. 엔딩

배역마다 4~5개. 마지막 장면 뒤의 성격·수치 조건을 위에서부터 보고 처음 맞는 엔딩이 된다.
마지막 엔딩은 조건이 없는 기본 엔딩. 모든 엔딩은 실제로 도달할 수 있다(테스트가 3^7=2,187가지 인생을
배역마다 전부 살아 보고 확인한다).

## §8. 점수

```
인생 점수 = 배역 기본점(par) + 배역 배율(rate) × (늘어난 수치 합 × 4 + 엔딩 보너스)   (0 미만이면 0)
최종 점수 = 인생 점수 + 👏 받은 박수 × 2
```

- "늘어난 수치"는 시작 수치 대비 — 부자로 태어난 배역은 얼마나 가졌나가 아니라 얼마나 나아졌나로 본다.
- 동점이면 ❤️ 관계 → 😊 행복 → 앞 좌석.

## §9. 밸런스 (셀프플레이)

배역마다 힌트가 얼마나 정직한지(함정의 깊이)와 엔딩 보너스의 폭이 달라서, 보정 전에는 같은 실력으로
살아도 점수대가 크게 달랐다. 봇 Lv.1(힌트와 ⚡에 끌림) / Lv.5 / Lv.10(남은 인생을 끝까지 내다봄)으로
배역당 300~1,500판씩 돌려 par·rate를 맞췄다.

| 배역 | par | rate | 보정 전 Lv.1 / Lv.10 | 보정 후 Lv.1 / Lv.5 / Lv.10 |
|---|---:|---:|---|---|
| 노비 | −34 | 1.35 | 126 / 150 | 82 / 110 / 115 |
| 양반 | −6 | 1.15 | 116 / 145 | 83 / 108 / 115 |
| 임금 | −7 | 1.2 | 114 / 141 | 82 / 109 / 114 |
| 재벌 3세 | 46 | 0.7 | 86 / 139 | 78 / 110 / 116 |
| 흙수저 | 42 | 0.7 | 94 / 146 | 80 / 108 / 116 |
| 회사원 | 58 | 0.7 | 68 / 124 | 78 / 112 / 117 |
| CEO | 21 | 0.8 | 117 / 156 | 84 / 110 / 114 |
| 아들·딸 키우기 | −38 | 1.6 | 117 / 131 | 84~86 / 104 / 108 |
| 아이돌 | −20 | 1.15 | 128 / 156 | 82 / 110 / 113 |

- 보정 전 배역 간 편차: Lv.1 60점, Lv.10 32점 → 보정 후 Lv.1 7.5점, Lv.5 7.7점, Lv.10 8.7점.
- 남은 차이: 아이 키우기는 높은 레벨 천장이 조금 낮다(108 vs 113~117). rate 상한(1.6)을 더 올리면
  수치 1점이 6점을 넘어 박수(2점)가 무의미해져서 여기서 멈췄다.
- 봇: Lv.1은 "힌트 수 + ⚡"로 고르고, Lv.10은 그 선택 뒤 남은 모든 인생(최대 3^6)의 최고점·평균을
  내다본다(배역당 상태 수가 적어 통째로 기억). 모든 배역에서 Lv.10 평균 > Lv.1 평균 + 8.
- 테스트 `LifeSkit.test.ts`: 레벨별 배역 간 편차 < 12, Lv.10 > Lv.1 + 8.

## §11. 화면·소리

- 3D 무대: 붉은 막 + 그림 배경(세트 9종: 초가집 마당·양반댁 대청·궁궐·장터·사무실·집·교실·밤거리·무대)과
  소품. 내 캐릭터(VRM, 배역 머리 장식)와 상대역이 마주 선다. 고르는 중엔 턱을 괴고, 공개 때 결과에 따라
  만세 / 축 처짐 / 으쓱. 장면이 바뀌면 막이 닫혔다 열린다. 2D 전환 가능.
- 대사 말풍선·자막·결과 문장은 DOM으로 얹는다.
- 공개 화면에서 다른 사람 카드의 🎬 무대에서 보기로 그 사람의 장면을 무대에 올릴 수 있다.
- 엔딩 화면: 순위 · 엔딩 · 점수 내역 · 📜 인생 돌아보기(7장면 다시 보기).
- 접근성: 좌석은 색 + 모양(●◆▲■★✚⬟♥), 수치 변화는 색 + ▲▼ 기호.
- 소리 "Curtain Up Shuffle"(112 BPM 셔플, 공개 때 브라스·라이드 추가): 선택 확정 · 두구두구 챙 ·
  잘 풀림 / 처지는 나팔 · 성격 획득 · 나비효과 · 박수 · 슬레이트 · 엔딩.

## §12. 온라인

- 방 코드 4자리, 방장이 인원(1~8)·시간을 정한다. 일찍 시작하면 채워진 자리만으로 시작한다.
- 이탈하면 투표로 AI가 이어받고, 돌아오면 되찾는다. 가장 낮은 접속 좌석이 봇과 시간 초과를 처리한다.
- 방장 상태 요약으로 어긋남을 감지해 다시 맞춘다(공용 desync guard).
