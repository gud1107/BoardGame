# 🧱 무너지는 탑 오르기 (Crumbling Tower Climb) — 룰북 · 설계서

> 자체 창작 게임. 앱 id `crumble-climb`, 코드 `src/games/crumbleClimb/`.
> "올라가는 레이스 + 아래에서 차오르는 위험" 장르의 공식을 분석해 **나선 탑·꼴찌/탈락자 방해 카드·첫 등정 뒤 붕괴 가속**으로 다시 설계했다. 특정 게임의 이름·캐릭터·맵·수치를 옮기지 않았다.
> 이 문서가 규칙의 원전이다. 수치는 `data.ts`와 같아야 하고, 바꾸면 `balance.sim.test.ts`로 다시 확인한다.

## §1 한 줄 소개

노을 진 구름 바다 위 **돌기둥 탑**. 기둥 둘레를 나선으로 도는 발판을 2~6명이 동시에 뛰어올라 **꼭대기 왕관 발판에 먼저 오르는** 실시간 3D 레이스. 탑은 **아래부터 무너져 올라오고**, 뒤처진 사람은 방해 카드로 선두를 괴롭힌다.

- 인원 2~6명 (빈자리는 AI 봇 Lv.1~10), 혼자 연습 가능
- 한 판 1/3/5라운드 (기본 3) · 라운드당 보통 40~50초 · 한 판 2~9분
- 장르: 파티 · 실시간 액션 · 레이스 · 플랫포머

## §2 구성 요소

| 요소 | 설명 |
|---|---|
| 기둥 | 반지름 1.7m 돌기둥. 몸은 뚫지 못한다 |
| 바닥 원판 | 반지름 6.8m 출발 원판. 가장자리에 낮은 울타리(바닥이 무너지기 전까지 밖으로 안 떨어짐) |
| 본길 | 바닥부터 꼭대기까지 기둥 둘레를 나선으로 도는 발판 약 37~40개. 이웃끼리 중심 거리 2.3~3.1m, 높이 차 0.55~0.95m — 늘 보통 점프로 닿는다 |
| 샛길 | 본길 옆(안쪽/바깥쪽 줄)에 붙는 발판, 탑마다 8~27개(중앙값 17). 아래쪽(본길 4번째까지)엔 출발 혼잡을 풀려고 더 자주 |
| 왕관 발판 | 꼭대기(약 30m) 금색 원판. 닿으면 등정. 무너지지 않는다 |
| 캐릭터 | 프로필 VRM 캐릭터 + 자리 색 헬멧·등 깃발·발밑 고리. 자리마다 **색 + 모양** ● 주황 · ▲ 파랑 · ■ 노랑 · ◆ 초록 · ★ 보라 · ♥ 분홍 |

라운드마다 씨앗(`towerSeed`)으로 **새 탑**을 짓는다. 방장·손님이 같은 씨앗으로 같은 탑을 지으므로 스냅샷엔 발판마다 바뀌는 값(무너짐·금·얼음)만 담는다.

## §3 목표와 승리

라운드마다 **꼭대기에 먼저 오른 순서대로** 점수를 모은다. 모든 라운드가 끝나면 점수가 가장 높은 사람이 우승.

## §4 라운드 진행

1. **출발**: 모두 바닥 원판 위, **첫 본길 발판 중심에서 똑같이 2.7m 떨어진 점들**에 선다(자리 이점 없음). 라운드마다 자리 순서를 섞는다.
2. **카운트다운**: 1라운드 4초, 이후 3초.
3. **오르기**: 출발 7초 뒤부터 붕괴선이 올라온다(§6). 아이템(§8)·방해 카드(§7).
4. **🏁 첫 등정**: 누군가 왕관 발판에 닿으면 붕괴 속도 ×1.7.
5. **라운드 끝**: 모두 등정하거나 휩쓸리면 결과 6초 → 다음 라운드. 안전장치 120초.

## §5 조작과 몸

| 조작 | 키보드 | 휴대폰 | 내용 |
|---|---|---|---|
| 이동 | WASD/방향키 | 왼쪽 조이스틱 | 카메라 기준 — ←→ 탑 둘레, ↑ 기둥 쪽 · ↓ 바깥쪽. 달리기 5.2m/s |
| 점프 | Space/K | ⤴ | 초속 8.6 → 최고 약 1.68m. 코요테 타임 0.11초, 입력 버퍼 0.16초 |
| 밀치기 | Shift/J/E | 👊 | 바라보는 쪽 ±70°, 1.75m 안, 높이 차 1m 안 → 7.2m/s로 밀고 3.2m/s 띄움, 0.38초 휘청. 재사용 3.2초 |
| 방해 카드 | 1~3 | 카드 버튼 | §7 |

- 땅에선 원하는 속도로 바로 붙고(14/초), 공중에선 천천히 틀고(5/초), 🧊 얼음판 위에선 미끄럽다(1.6/초).
- 중력 22m/s². 발판은 **아래에서 뚫고 올라갈 수 있고**(머리 부딪힘 없음), 위에서 내려오면 선다. 몸 반지름 0.35m 중 0.22m가 걸쳐 있으면 선다.
- 몸끼리는 겹치지 않게만 밀어낸다(점수 없음).
- **카메라**: 따라가는 사람(나, 끝났으면 아직 오르는 사람 중 선두)의 기둥 둘레 각도로 돌아 늘 기둥 바깥에서 본다. 보드는 카메라 각으로 화면 방향을 월드 방향으로 바꿔 보낸다(`view.ts` `screenToWorld`).

## §6 발판과 붕괴

| 발판 | 모양(색만으로 구분하지 않음) | 규칙 |
|---|---|---|
| 돌 | 베이지 둥근 원판 | 평범 |
| 금 간 | 갈색 **9각** 원판 + 금 무늬 (2D: 톱니) | 처음 밟히고 0.9초 뒤 무너짐 → 3초 뒤 다시 생김 |
| 트램펄린 | 초록 + 흰 고리 + 아래 스프링 (2D: ⬆) | 밟으면 초속 11.3(약 2.9m)으로 튕김. 샛길에만 |
| 움직이는 | 파랑 + 화살표 (2D: ↔) | 기둥 둘레로 ±0.32rad, 4.2초 주기. 선 사람을 실어 나른다. 본길에만 |
| 왕관 | 금색 + 왕관 + 깃발 | 닿으면 등정 |

- 본길의 금 간·움직이는 발판은 5번째부터, 연달아 나오지 않는다.
- **붕괴선**: −2m에서 출발, 출발 7초 뒤부터 초속 0.3m에서 1초마다 0.015씩 빨라짐(최대 1.6), 🏁 뒤 ×1.7. 붕괴선 아래 발판은 영영 사라짐(왕관 제외). 붕괴선 1.8m 위까지는 빨갛게 흔들리며 경고. 붕괴선보다 1.2m 아래로 떨어지면 **휩쓸림**(그 라운드 끝, 0점).

## §7 🧱 방해 카드 (끌 수 있음)

- **받는 사람**: 휩쓸린 사람은 9초마다, 아직 오르는 **꼴찌**는 선두보다 6m 이상 낮을 때만 12초마다. 출발 10초 뒤부터. 등정한 사람은 받지 않는다.
- 4종 중 3장이 나오고 6초 안에 하나를 고른다(안 고르면 무작위). **과녁 = 쓰는 순간 가장 높이 있는 사람**(쓴 사람 제외).

| 카드 | 효과 |
|---|---|
| 🪨 낙석 | 선두 자리 + 주변 1.1~1.8m 두 곳, 돌 3개. 빨간 경고 원 1.1초 뒤 떨어져 반경 0.95m 안이면 휘청(4.6m/s 밀림) |
| 🧊 얼음판 | 선두 높이 −0.5~+4m 발판이 7초 동안 미끄러움 |
| 💨 돌풍 | 0.9초 경고 뒤 3.2초 동안 선두 높이 −2m 위 모두를 탑 바깥쪽(+옆)으로 9m/s² |
| 🧱 흔들기 | 선두가 선 발판 + 그 위 본길 두 칸이 1초 뒤 무너짐(3초 뒤 다시 생김) |

- 🛡 방패는 낙석·돌풍(시작 순간)·밀치기를 한 번 막는다.

## §8 아이템 (끌 수 있음)

5.5초마다 하나(최대 3개, 15초 뒤 사라짐). **오르는 사람 중 가장 낮은 사람 근처~중간 높이**(아래쪽 절반)의 돌·움직이는·트램펄린 발판에 뜬다 — 뒤처진 사람을 돕는 장치.

| 아이템 | 효과 |
|---|---|
| 🪶 깃털 | 공중에서 한 번 더 점프(초속 8.0). 하나만 들 수 있음 |
| ⚡ 번개 신발 | 6초 동안 30% 빨리 |
| 🛡 방패 | 15초 동안 밀치기·낙석·돌풍 한 번 막기 |

## §9 화면

- 위 HUD: 라운드, 경과 시간(🏁 뒤 빨강), 내 높이/탑 높이, **붕괴까지 남은 m**. 점수판 칩에 각자 높이·👑등수·💨, 선두 🔝.
- 오른쪽 **높이 막대**: 모두의 모양 기호 + 붕괴 먼지 + 빨간 경고선 + 👑. 3D에서 기둥 뒤에 가려진 사람도 여기서 보인다.
- 내 발밑 경고 글자(소리 없이도): 붕괴선 근접 · 발판 무너짐 · 머리 위 낙석 · 돌풍 · 얼음판.
- 방해 카드 고르기 판(남은 초 + 과녁 이름), 라운드 결과(등정 순서·휩쓸린 높이), 최종 결과 + 상(가장 빠른 등정·등정왕·밀치기 왕·낙석 저격수·통통 튀는 사람).
- ⚙️ 3D/🖼️ 2D 옆모습(탑 둘레를 펼친 그림)·화질, ⛶ 전체화면.

## §10 온라인

- 방 만들기·초대 코드·봇 좌석은 살얼음 파티와 같은 프로토콜. **방장 기기가 60Hz 고정 스텝으로 시뮬레이션**, 스냅샷 10번/초, 손님은 입력(`in`)만 보낸다.
- 남의 몸은 110ms 늦게 보간, 내 몸은 최신 스냅샷 + 속도로 최대 120ms 앞서 그린다.
- 사람이 나가면 10초 뒤 AI가 대신(🤖대신), 돌아오면 돌려받는다. **방장이 나가면** 3초 뒤 남은 사람 중 자리 번호가 가장 낮은 사람이 마지막 스냅샷으로 이어받는다.

## §11 3D 연출

노을 하늘·구름 바다, 벽돌 기둥과 횃불, 꼭대기 처마, 발판 종류별 모양, 금 간·흔들린 발판 떨림, 무너진 발판 낙하, 붕괴 먼지 원판 + 먼지 입자 + 빨간 경고 띠, 낙석 경고 원과 떨어지는 돌, 돌풍 줄기, 아이템 이모지, VRM 캐릭터(달리기·점프·만세 튕김·허우적 낙하·휘청·밀치기·환호·실망, 붕괴 근접 시 무릎 떨림), 착지 먼지·트램펄린 고리·밀치기 부채꼴·맞음 별·조각·등정 꽃가루, 카메라 흔들림.

## §12 기록 · 업적

상세 기록: finishes, roundWins, caught, jumps, airJumps, bounces, shoves, shoveHits, drops(3m 넘는 낙하), cards, sabHits(내 낙석에 맞은 사람), items, blocks, maxHeight, minClimbSec(가장 빠른 등정), maxScore.
업적: 첫 등정 · 탑의 주인(라운드 1등) · 등반 장인(20번) · 번개 등반(35초 안) · 밀치기 장인(30번) · 낙석 저격수(5명) · 통통 등반가(트램펄린 50번).
