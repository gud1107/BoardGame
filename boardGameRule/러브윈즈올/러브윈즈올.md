# 러브 윈즈 올 (Love Wins All) 완전 룰북

> 넷플릭스 예능 〈데스게임: 천만원을 걸어라〉 시즌1 3회차(유리사 vs 펭수 매치)에서 사용된 게임입니다. 이 문서는 방송·공개 정보를 바탕으로 재구성한 비공식 정리본이며, 실제 방송에서 공개되지 않은 세부 규칙은 "미공개"로 표시했습니다.

---

## A. 게임 한 줄 요약

가위바위보에 '러브'라는 특수 패가 더해진 카드로 족보를 만들고, 포커처럼 베팅을 주고받으며 상대의 칩을 모두 가져오면 승리하는 1:1 대결 게임입니다.

## B. 준비물

| 구성 | 수량 |
|---|---|
| 가위 카드 | 12장 |
| 바위 카드 | 7장 |
| 보 카드 | 7장 |
| 러브 카드 | 4장 |
| **카드 총합** | **30장** |
| 개인 칩 | 각자 25개 (연습 게임은 20개) |

## C. 족보표 (숫자가 낮을수록 강함)

| 순위 | 족보 | 조건 |
|---|---|---|
| 1위 | 러브 윈즈 올 | 러브 카드 3장 |
| 2위 | 트리플 | 가위·바위·보 중 같은 카드 3장 |
| 3위 | 투 러브 | 러브 카드 2장 + 나머지 1장 |
| 4위 | 믹스 | 가위·바위·보가 각각 1장씩 |
| 5위 | 더블 | 러브 없이 같은 가위바위보 카드 2장 |
| 6위 | 원 러브 | 러브 카드 1장 |

## D. 동순위 승부 판정법

- **같은 등급끼리 맞붙으면** 우선 가위바위보 상성으로 승부를 가립니다.
- 상성마저 같다면(예: 둘 다 '가위' 트리플) 나머지 카드의 상성으로 다시 비교합니다.
- **투 러브끼리 대결**하면 러브가 아닌 나머지 카드 1장의 가위바위보 상성으로 승부를 결정합니다.
- **원 러브끼리 대결**하면 곧바로 무승부 처리됩니다.

## E. 카드 등장 확률 (참고용 계산치)

| 족보 | 등장 확률 |
|---|---|
| 러브 윈즈 올 | 약 0.1% |
| 트리플 | 약 7.2% |
| 투 러브 | 약 3.8% |
| 믹스 | 약 14.5% |
| 더블 | 약 42.4% |
| 원 러브 | 약 21.4% |

※ 러브 윈즈 올은 사실상 잘 나오지 않는 최상위 희귀 족보입니다.

## F. 라운드 진행 순서

1. **선공 결정**: 1라운드는 추첨, 2라운드부터는 직전 라운드 승자가 선공을 맡습니다.
2. **기본 베팅**: 두 플레이어 모두 칩 1개씩 필수로 베팅한 뒤 카드 3장을 받습니다.
3. **1차 베팅**: 통상적인 포커식 베팅(콜/레이즈/폴드)을 진행합니다.
4. **1장 공개 + 족보 선언**: 각자 카드 1장을 오픈하고, 자신의 족보가 무엇인지 선언합니다. **이 선언은 거짓말(블러핑)을 해도 됩니다.**
5. **2차 베팅**: 선언 내용을 참고해 다시 한 번 베팅을 진행합니다.
6. **전체 공개 및 승패 판정**: 남은 카드를 모두 오픈해 족보를 비교, 더 높은 쪽이 해당 라운드(팟)를 가져갑니다.

## G. 무승부·폴드 처리

- 두 족보가 완전히 동일해 **무승부**가 나오면, 판돈(팟)은 즉시 나누지 않고 **다음 라운드로 이월**됩니다.
- 어느 한쪽이 **베팅 도중 포기(폴드)** 하면 카드는 공개하지 않고 그대로 라운드가 종료됩니다.
- 단, 실수로 카드가 먼저 노출된 경우에는 카드를 바꾸지 않고 그대로 진행합니다.

## H. 히든(?) 규칙 – 거짓 선언에 대한 페널티

방송에서 확인된 바로는 **거짓 족보 선언에 대한 별도 페널티 규정이 없습니다.** 즉 "선언"은 실질적으로 베팅을 한 번 더 하는 것과 크게 다르지 않으며, 순수한 심리전 용도로만 기능합니다.

## I. 승리 조건

상대방의 칩 25개를 전부 가져오는 순간 즉시 게임이 종료되고 승리합니다.

## J. 연습 게임

본 게임 시작 전, 규칙 이해를 돕기 위한 연습 게임을 먼저 진행합니다. 연습 게임은 칩 20개로 시작하며 나머지 진행 방식은 본 게임과 동일합니다.

## K. 게임의 성격 (참고)

- 유형 분류상 **블러핑·포커류**에 가깝습니다.
- 가위바위보 상성이 더해져 있지만, 거짓 선언 페널티가 없어 실질적으로는 "패가 좋은가 아닌가"를 두고 벌이는 이지선다 심리전에 가깝습니다.
- 한 번 사용된 카드는 다음 덱 교체 전까지 다시 등장하지 않으므로, 트리플 등 상위 족보가 나올 확률은 어느 정도 카운팅이 가능합니다.

## L~Z. 부록 — 개선판 "러브 윈즈 올 2" (시즌2 6강전 버전)

시즌1 방송 이후 "운적 요소가 지나치게 크다"는 지적을 반영해 시즌2에서 규칙이 대폭 보완되었습니다. 주요 변경점만 정리합니다.

### 카드 구성 변경
가위 18장, 바위 12장, 보 12장, 러브 6장, **라이어 1장** — 총 49장

### 카드 분배 방식 변경
- 처음에 **공유 카드 1장**(테이블 중앙 공개)과 **개인 카드 3장**을 조합해 총 4장으로 족보를 만드는 방식으로 바뀌었습니다.
- 이는 텍사스 홀덤과 유사한 구조로, 카드 카운팅과 확률 계산의 비중을 높인 변화입니다.

### 족보표 (9단계로 세분화, 숫자가 낮을수록 강함)

| 순위 | 족보 |
|---|---|
| 1 | 러브 윈즈 올 (러브 4장) |
| 2 | 쓰리 러브 (러브 3장) |
| 3 | 포카드 (러브 아닌 카드 4장 동일) |
| 4 | 믹스 (러브·가위·바위·보 각 1장) |
| 5 | 투 러브 |
| 6 | 투페어 |
| 7 | 트리플 |
| 8 | 원페어 |
| 9 | 원 러브 |

### 라이어 카드
- 원하는 어떤 조합으로든 자유롭게 선언할 수 있는 조커 성격의 카드입니다.
- 단, **라이어 카드로 승부에서 패배하면 상대에게 칩 5개를 추가로 지불하는 페널티**가 있습니다. 같은 등급끼리 비교될 경우에도 라이어 카드 쪽이 패배 처리됩니다.

### 칩 및 종료 조건
- 시작 칩은 35개로 증가했습니다.
- 한 플레이어가 상대의 칩을 모두 획득하면 즉시 승리합니다.
- 7라운드가 끝나면 새 덱으로 전량 교체합니다.
