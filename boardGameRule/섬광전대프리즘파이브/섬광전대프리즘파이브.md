# 섬광전대 프리즘파이브 — 룰북 & 상세 설계서 (A–Z)

> 요청: "후레쉬맨 같은 스타일의 게임 — 격투용 피격 모션과 콤보, 스킬, 필살기가 있고 잔몹과 보스를 깨나가는 시나리오"
> 구현: `src/games/prismFive/` · 게임 id `prism-five` · 1인용 실시간 벨트스크롤 액션 (Canvas 2D)
> 작성일 2026-10-23. 수치의 **원본은 `data.ts`** 이며 이 문서는 그 설계 의도를 설명한다. 둘이 어긋나면 `data.ts`가 맞다.

## A. 컨셉 · 저작권

- 80년대 슈퍼전대(「초신성 플래시맨」 등)의 문법을 오마주한 **오리지널** 작품. 상표·캐릭터는 사용하지 않는다.
  - 게임명 「섬광전대 프리즘파이브」, 적 조직 「암흑제국」, 로봇 「그랜드 오리온」는 모두 자체 창작이다.
  - 그래픽은 전부 코드로 그린다(외부 이미지·음원 없음).
- 전대물의 필수 장면을 전부 게임 구조에 넣었다:
  **변신 → 이름 대기 + 컬러 폭발 → 졸개 소탕 → 괴인 격파 → 거대화 → 로봇 합체 → 필살기로 마무리 → 폭발.**

## D. 좌표 · 판정 모델

- `x` 가로(스테이지 길이 2600~3600), `z` 깊이 0~150(화면 아래쪽일수록 앞), `y` 높이(공중).
- 화면은 640×360 논리 해상도. 깊이에 따라 0.88~1.04배 원근 스케일을 준다.
- 공격 판정 = 앞쪽 거리 `x:[from,to]` × 깊이 반폭 `z` × 높이대 `y:[lo,hi]`. 맞는 쪽 몸 반지름(14×스케일)을 더한다.
- 보스 표는 "히어로 크기" 기준으로 쓰고 보스 스케일만큼 키운다. 로봇·거대 괴인 표는 처음부터 거대 단위다.
- 한 번의 기술 인스턴스에서 **같은 타격 번호는 대상마다 1회만** 맞는다(다단히트는 타격 번호를 여러 개 둔다).

## F. 콤보 시스템

1. **체인**: 약공격 모션의 `cancel` 틱 이후 약공격 입력 → 다음 타.
2. **분기**: 체인 0타 이후 강공격 → 띄우기 / 체인 1타 이상 이후 강공격 → 피니셔.
3. **점프 추격**: 띄우기가 적중했으면 cancel 이후 점프 → 높은 점프(vy 11)로 따라 올라간다.
4. **공중 콤보**: 공중 약공격 체인. 공중에서 적중할 때마다 히어로가 살짝 뜬다(점프당 최대 6회). 공중 강공격 = 다이브(내리꽂기 → 상대 **지면 바운드** → 한 번 더 띄울 수 있음).
5. **스킬 캔슬**: 일반기가 한 번이라도 적중했으면 언제든 스킬로 끊을 수 있다.
6. **회피 캔슬**: 적중 후 EN 10을 내고 회피로 끊는다.
7. **벽꽝**: 화면이 잠긴 상태에서 속도 5 이상으로 날아간 적이 벽에 닿으면 반대로 튕기고 살짝 뜬다 → 콤보 연장.

### F-1. 보정 (무한 콤보 방지)
- 공중 저글 카운트가 쌓일수록 **중력 +3%/타**, 띄우기 힘 감소(최저 55%).
- 저글 7타째부터 **데미지 5%씩 감소**(최저 40%).
- 저글 **14타 초과 → MAX**: 무적으로 떨어진다.
- 다운된 적은 맞지 않는다(OTG 판정 기술만 1회).

### F-2. 콤보 카운터
- 마지막 적중 후 **90틱** 동안 다음 적중이 없으면 끊긴다. 피격돼도 끊긴다.
- 끊길 때 콤보가 5 이상이면 보너스 `콤보^1.5 × 12 × 난이도 배율`.

- 포즈 = 13개 각도(몸 기울기, 다리 4, 팔 4, 머리, 전신 회전, 띄움 높이). 공격은 애니 종류별 **[준비, 타격]** 키프레임 → 시작~첫 판정 틱까지 준비 보간, 판정 순간 3틱 만에 타격 포즈, 이후 회수 보간. 다단 러시는 준비↔타격을 진동시킨다.
- 레이어 순서: 망토 → 먼 팔·다리(어두운 톤) → 몸통 → 가슴 장식 → 가까운 다리 → 머리 → 어깨 패드 → 가까운 팔 → 무기.
- 히어로 스킨은 다섯이 전부 다르다: 머리(불꽃 볏 투구 / 후드 / 고글 헬멧 / 돌가면 / 포니테일+반가면), 등(머플러 / — / 배낭 / — / 코트 자락), 가슴(흉갑+불꽃 / 지퍼+번개 / 탄띠 / 바위판+견갑 / 띠+물결), 장갑·부츠 색, 체격(0.93~1.2), 무기. 오버히트·전하 상태는 투구 슬릿·건틀릿 발광으로 보인다, 졸개(검은 전신 타이츠, 갈비뼈 무늬, 붉은 외눈 마스크), 보스 5종(뿔·거울 얼굴·집게·흑기사 투구·황제 왕관 + 망토), 킹로보(V자 뿔, 흉부 삼각 코어).

## S. 사운드 (전부 합성)

- BGM 3종: 스테이지(D장조 I–V–vi–IV 행진, 150BPM, 8분음 베이스 + 금관풍 리드 + 파워코드), 보스(D단조 160BPM), 거대전(120BPM 찬가).
- 효과음: 휘두르기 약/강, 타격 약/강/피격, 가드(금속음), 사격·빔·화살·로켓 펀치, 폭발 소/대, 스킬, 필살(5음 상승), 어시스트, 섬광 회피(차임), 브레이크(유리), 패리(쨍), 페이즈 전환, 보스 등장, 필살 준비, 변신(스윕 + 화음), GO, 아이템, 스톡 소실, 콤보 종료, 낙법, 클리어 팡파르, 게임오버.

## T. 접근성

- **화면 흔들림 끄기**, **번쩍임·잔상 줄이기**(흰 플래시·화이트아웃·잔상·섬광선·슬로 틴트 제거, 예고 "!" 깜빡임 대신 상시 표시). OS "동작 줄이기"가 켜져 있으면 둘 다 기본 켜짐.
- 위험은 색만으로 전달하지 않는다: 모든 적 공격 = **! 아이콘** + 준비 포즈 떨림. 저격 조준선은 고정 시 굵어진다.
- 소리 없이도 플레이 가능: 모든 사운드 신호에 대응하는 화면 신호가 있다(배너·링·숫자).
