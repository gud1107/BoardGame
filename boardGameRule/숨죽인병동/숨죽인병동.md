# 숨죽인 병동 (Hushed Ward) — 룰북 · 설계서

> 1~4인 협동 · 1인칭 3D 공포 · 한 판 5~12분 · 게임 id `hushed-ward` · 구현 `src/games/hushedWard/`
>
> 자체 창작 게임이다. "소리로 사냥하는 눈먼 괴물", "손전등과 공포 수치", "협동 탈출"은 공포 장르에서 널리 쓰는
> 장치이고, 이름·배경·지도·수치·귀신(청귀)·종(정적) 규칙은 이 프로젝트에서 새로 만들었다(특정 게임의 맵·캐릭터·수치를 옮기지 않음).

## §1 한 줄 소개

새벽 3시, 문 닫은 요양병원 3병동. 들어서자 현관이 잠겼다. 손전등 하나씩 든 1~4명이 병동 곳곳의 서랍에서
**🧧 봉인 부적**을 찾아 기도실 제단에 붙이고 현관으로 빠져나간다. 병동을 떠도는 **청귀(聽鬼)** 는 눈이 꿰매어져
**소리만 듣는다** — 발소리, 문소리, 그리고 무서워서 뛰는 심장 소리까지.

**핵심 재미 3가지**
1. **소리를 관리한다** — 모든 행동에 "소리 반경"이 있고 화면에 항상 보인다. 빨리 갈수록 시끄럽다.
2. **빛 ↔ 공포 ↔ 소리가 맞물린다** — 건전지를 아끼려 불을 끄면 공포가 오르고, 공포가 오르면 심장 소리가 나서 가만히 있어도 들킨다. 숨을 참으면 감출 수 있지만 6초뿐이다.
3. **종이 울리면 멈춘다** — 가끔 온 병동이 귀를 기울이는 5초. 모두가 동시에 얼어붙는 "무궁화 꽃이 피었습니다"의 순간.

## §2 승리와 패배

- **팀 승리**: 봉인 부적을 전부 제단에 붙이면 현관 자물쇠가 풀린다. 그 뒤 **한 명이라도** 현관에 닿으면 승리.
- **패배**: 살아 움직이는 사람이 아무도 없는데 탈출자가 0명이거나, 새벽 **4:44**(실제 12분)가 됨.
- 판은 "살아 있는 사람이 0명"이 되는 순간 끝난다(모두 탈출·쓰러짐·끝남). 쓰러진 동료를 두고 마지막 사람이 나가면 그 동료는 못 나온다.
- **등급**: S 전원 탈출 + 아무도 안 붙잡힘 · A 전원 탈출 · B 절반 이상 · C 한 명 이상 · F 실패.
- 순위 기록: 탈출한 사람 1위, 나머지 2위(아무도 못 나가면 모두 2위).

| 인원 | 필요한 봉인 부적 | 시작 🧿 수호 부적 |
|---|---|---|
| 1 | 3장 | 1장 (+순한 밤이면 1장 더) |
| 2 | 4장 | 0 |
| 3 | 5장 | 0 |
| 4 | 6장 | 0 |

## §4 소리

모든 소리는 **반경(m)** 이 있고, 청귀의 귀까지 **길을 따라 잰 거리**(벽을 뚫지 못한다)와 비교한다.
닫힌 문 하나는 소리를 5m만큼 막는다.

| 행동 | 반경 |
|---|---|
| 앉아 걷기 · 가만히 | 0 (정적 중 앉아 걷기는 1.2) |
| 걷기 | 5m |
| 달리기 | 13m |
| 문 여닫기 | 7m (앉아서 하면 0) |
| 서랍 뒤지기 | 3m |
| 동료 일으키기 | 2.5m |
| 심장 소리 | 4m (공포 65↑) / 6.5m (공포 85↑) |
| 숨 터짐 "헉!" | 9m |
| 부적 붙이기 | 14m (제단에서) |
| 약병 깨짐 | 16m (깨진 자리에서) |
| 현관 경보 | 40m (현관에서, 자물쇠가 풀릴 때 한 번) |

청귀의 청력 배수 = 난이도 × (1 + 0.06 × 붙인 부적 수) × (1 + 0.05 × (인원 − 1)) × (배부른 동안 0.45) × (정적 중 3).

## §5 청귀(聽鬼)

| 상태 | 행동 | 속도 |
|---|---|---|
| 잠 | 시작 12초 동안 | — |
| 어슬렁 | 무작위 방으로. 35%(+부적당 10%, 최대 80%)는 누군가의 6~16m 근처로 | 1.5 (+부적당 0.12) |
| 확인 | 들린 자리로 가서 3.5초 귀 기울임 | 2.7 |
| 귀 기울임 | 멈춰 서서 듣는다 ("딱…딱…" 소리가 멎는다) | 0 |
| 추격 | 마지막으로 소리 난 자리로 달려온다 | 4.3 (+부적당 0.07, 정적 중 들켰으면 ×1.12) |
| 붙잡음 | 3.2초 웅크림 → 11초 동안 귀가 어둡고 멀리 떠남 | 0 |
| 문 박차기 | 닫힌 문 앞에서 0.8초 뒤 "쾅" | 0 |

- **경계심**: 소리를 들을 때마다 `1 + (반경 − 거리) × 0.3`씩 쌓이고 초당 0.6 줄어든다. 사람 소리가 **4m 안**이거나 경계심이 **6**을 넘으면 추격. 그 밖에는 확인만.
- **추격 중**: 대상의 소리를 들을 때마다 목적지를 고친다. 2.6초 동안 못 듣고 그 자리에 닿으면 놓친다(귀 기울임으로). 훨씬 가까운 다른 사람 소리가 나면 갈아탄다.
- **붙잡힘**: 추격 대상이 1.0m 안이거나, 어떤 상태든 몸이 0.55m 안에 닿으면. 복도(폭 2m)에서 벽에 바짝 붙으면 중심에서 0.7m라 스쳐 지나간다. 문간(폭 1.4m)에서는 못 피한다.
- **약병**: 깨진 자리로 확인하러 간다. 추격 중에도 대상이 4.5m보다 멀면 돌려세운다.
- 사람 달리기 4.8 / 걷기 2.6 / 앉아 걷기 1.35 m/s. 달리기 체력은 약 4.5초, 다 쓰면 25%까지 찰 때까지 못 달린다.

## §6 정적 (종)

- 첫 종은 45~60초, 그 뒤 55~80초마다(부적 한 장당 4초 짧아지고 최소 34초, 난이도 배수 적용).
- 종 세 번(3.5초 예고) → **5초 동안** 청귀가 멈춰 서고 **모든 소리 반경 ×3**.
- 그동안 사람 소리가 들리면 바로 빠른 추격, 물건 소리면 확인.
- 추격·붙잡는 중에는 종이 미뤄진다. 예고 중에 추격이 벌어지면 그 종은 취소.
- 들키지 않고 넘기면 기록(`hushOk`)에 남는다.

## §7 공포 · 숨 · 손전등

- **공포 0~100** (초당): 어둠 +2.0 / 불빛 −1.6 / 청귀가 10m 안이면 가까울수록 최대 +7 / 정적 중 +1.5 / 동료가 5m 안 −0.8. 동료가 눈앞(8m)에서 붙잡히면 +15. 일으켜진 직후 50.
- 동료의 켜진 손전등 4m 안에 있으면 내 것이 꺼져 있어도 "불빛"으로 친다.
- **숨 참기** 최대 6초(초당 0.7 회복). 참는 동안 심장 소리 없음. 0이 되면 "헉!"(9m) + 3초 잠금. 달리는 중에는 못 참는다.
- **손전등** 100%로 170초, 시작 80%. 15% 아래면 깜빡인다. 청귀는 빛을 못 본다.

## §8 물건 (서랍 26개)

| 물건 | 수 | 효과 |
|---|---|---|
| 🧧 봉인 부적 | 인원별 3~6 | 제단에 붙인다(한 장 2.5초). 되도록 서로 다른 방에 숨는다 |
| 🔋 건전지 | 3+인원 (최대 6) | 손전등 +55% |
| 🍾 빈 약병 | 4+인원 | 던져서 깨뜨린다(4~12m, 위를 볼수록 멀리). 최대 2개 |
| 💊 진정제 | 2 (3인 이상 3) | 공포 −55. 최대 2개 |
| 🧿 수호 부적 | 1 (순한 밤·보통만) | 붙잡힐 때 대신 타고 청귀를 5.5초 멈춘다 |
| 🕸️ 빈 서랍 | 나머지 | — |

서랍 뒤지기 2초. 더 들 수 없는 물건은 그대로 두고 온다(서랍은 안 뒤진 것으로 남는다).

## §9 협동과 온라인

- 붙잡히면 **쓰러짐**: 동료가 2m 안에서 4초 붙들면 일어난다. 70초 안에 못 일으키면 끝.
- 끝난 사람·탈출한 사람은 남은 동료의 눈으로 지켜본다(화면을 누르면 다른 동료).
- **판정은 방장 기기**(`sim.ts`, 20Hz). 사람의 몸(위치·시선·걷는 방식)은 각자 기기가 움직여 10번/초 `pos`로 알린다 — 1인칭이라 입력 지연이 없어야 하고, 협동 게임이라 위치를 믿어도 된다. 문·약병·진정제는 `act`.
- 스냅샷 `snap`은 경기 상태 전체(JSON)라 **방장이 나가면** 3초 뒤 자리 번호가 가장 낮은 사람이 이어받는다.
- 사람이 나가면 10초 뒤 AI 동료가 대신한다. 다시 들어오면 돌려받는다.
- 빈자리 AI 동료 Lv.1~10 (`bot.ts`): 사람과 같은 정보만 쓴다(청귀 소리가 들리는 13m 안에서만 위치를 안다). 레벨이 낮으면 늦게 반응하고 청귀 근처에서도 걷는다.

## §10 화면

- 1인칭 3D(three.js/R3F). 거의 깜깜한 병동을 손전등(그림자 드리움)으로 비춘다. 붉은 비상등 6개, 제단 촛불, 현관의 초록 비상구 표지.
- 청귀: 키 2.2m, 무릎까지 오는 팔, 꿰맨 눈, 커다란 귀. 귀 기울일 때 귀가 벌어지고 고개가 천천히 돈다. 추격 때는 팔을 뻗고 입이 벌어진다.
- 붙잡히는 순간: 고개가 강제로 청귀 쪽으로 돌아가고 화면이 붉게 번쩍인다. ⚙️ "놀람 연출 줄이기"로 약하게 할 수 있다.
- 공포가 오르면 화면 가장자리가 어두워지고 붉게 맥박친다. 정적 중에는 화면이 탈색되고 큰 "쉿"과 남은 시간이 나온다.

## §11 접근성

- 소리로만 전하는 신호는 없다: 청귀의 "딱…딱…"은 👂 ▮▮▮ 3단계 표시와 화면 가장자리 떨림으로, 종은 배너와 "쉿" 글자·화면 색으로, 내 소리는 🔇~🔊 아이콘과 반경 숫자로 나온다.
- 자리 구분은 색 + 모양(● ▲ ■ ◆).
- 휴대폰: 왼쪽 조이스틱(끝까지 밀면 달리기) + 오른쪽 끌어 시선 + 버튼 7개. 숨 참기·상호작용은 72px 큰 버튼.
- 사이트 소리가 꺼져 있으면 게임 위에 "소리 켜기" 안내가 뜬다.

## §14 아직 안 한 것

- 실제 여러 기기 온라인 플레이(방장 승계 포함)는 엔진 테스트로만 확인했다.
- 소리는 귀로 들어 보지 않았다(음량 균형, 좌우 방향감 없음 — 거리만 크기로 표현).
- 휴대폰 실기기 프레임·조작감 미확인. 포스터·호버 영상 없음.
