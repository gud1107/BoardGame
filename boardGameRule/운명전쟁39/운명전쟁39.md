# 0. 이 룰북의 규칙 상태

이 룰북은 방송에서 확인된 컨셉을 바탕으로, 실제 플레이 가능한 보드게임/디지털 게임으로 만들기 위해 제작자가 직접 확정한 **공식 규칙서**다.

Version 1.0까지 미확정으로 남아있던 다음 항목들이 이번 버전에서 전부 확정되었다:

* 45장 카드의 정확한 구성
* 카드 배분 방식과 라운드 내부의 "턴" 구조
* 카드 재사용/재셔플 방식
* 리버스 카드 다중 등장 처리
* 데스카드·리버스·0 카드의 상호작용
* 0 카드 동률 처리
* 정확한 점수 산식
* 최종 동점 처리

이 문서에는 더 이상 "미확정" 규칙이 없다.

---

# 1. 게임 개요

운명전쟁39는 카드의 강약을 이용해 다른 플레이어와 승부하면서, 동시에 **매 라운드 자신이 그 라운드에서 얻을 승수를 정확하게 예측하는 게임**이다.

게임은 총 9라운드로 진행되며, 라운드가 진행될수록(1라운드 → 9라운드) 한 라운드 안에서 벌어지는 승부(턴)의 수도 1턴에서 9턴으로 늘어난다.

플레이어는 단순히 강한 카드를 많이 쓰는 것이 목표가 아니라, **그 라운드에서 자신이 선언한 예측 승수와 정확히 같은 횟수만큼 승리하는 것**을 목표로 한다.

# 2. 플레이어 수

**정확히 5인 고정**으로 진행한다. 인원 가변은 지원하지 않는다.

* 플레이어 A, B, C, D, E (좌석은 게임 시작 시 무작위로 배정된다 — §9 참고)

---

# 3. 게임 구성물 — 45장 카드 (확정)

| 카드 종류 | 장수 |
| --- | --- |
| 0 | 5장 |
| 1 ~ 39 (각 숫자) | 1장씩 (39장) |
| 데스카드 | 1장 |
| **합계** | **45장** |

* 0을 제외한 모든 숫자(1~39)는 중복 없이 정확히 1장씩만 존재한다.
* 11, 22, 33은 **일반 숫자 카드이면서 동시에 리버스 효과를 가진 특수 카드**다. 즉 숫자값 11/22/33으로도 취급되고, 그 턴의 리버스 발동 여부를 계산하는 데도 사용된다.
* 데스카드는 숫자를 갖지 않는 별도의 특수 카드로, 1장만 존재한다.

---

# 4. 라운드 구조 — "라운드 R은 R장, R턴" (확정)

라운드 번호를 `R`이라 할 때:

* 각 플레이어는 그 라운드 시작 시 **정확히 R장의 카드**를 받는다. (1라운드=1장, 2라운드=2장, … 9라운드=9장)
* 그 라운드는 **R번의 턴(turn)**으로 구성된다. 각 턴마다 모든 플레이어가 카드를 1장씩 내서 승부한다.
* 한 라운드의 실제 승수(그 라운드 동안 자신이 이긴 턴의 수)는 **0 ~ R** 범위에서 나올 수 있다. (예: 3라운드라면 실제 승수는 0, 1, 2, 3 중 하나)

## 4.1 카드 배분 방식 (확정)

* **매 라운드 시작 시 45장 전체를 다시 섞어서** 그 라운드에 쓸 카드를 배분한다.
* 이전 라운드에서 사용(공개)된 카드도 **폐기되지 않고** 다음 라운드의 재셔플 대상에 다시 포함되어 재사용될 수 있다.
* 따라서 같은 카드(예: 데스카드, 특정 리버스 카드)가 여러 라운드에 걸쳐 반복해서 등장할 수 있다.

## 4.2 카드 선택 (확정)

* **1라운드**: 손패가 1장뿐이므로 선택의 여지가 없다 — 받은 카드를 그대로 낸다.
* **2라운드 이후**: 그 라운드에 받은 R장의 손패 중, 아직 내지 않은 카드를 매 턴마다 자유롭게 선택해서 낼 수 있다. (정해진 순서로 내야 하는 제약 없음)

---

# 5. 카드 공개 순서 (확정)

## 5.1 좌석 순서 (확정)

게임 시작 시 5명의 좌석 순서(시계방향 기준)를 **무작위로 배정**한다. 이 순서는 게임 내내 고정되며, 이후 모든 "시계방향" 진행과 1라운드의 동률 판정 기준으로 사용된다.

## 5.2 1라운드 (확정)

* 5명 전원이 **동시에** 카드를 공개한다. 실시간 선/후공 개념이 없다.
* 동률(§7.4의 0 카드 동률) 판정이 필요한 경우에만 §5.1의 무작위 좌석 순서를 기준으로 "먼저 낸 사람"을 가른다.

## 5.3 2라운드 이후 — 턴 단위 진행 (확정)

* 그 라운드의 **첫 번째 턴의 선공**은 직전 라운드의 **마지막 턴 승자**다.
* 이후 모든 턴에서, **그 턴의 승자가 곧바로 다음 턴의 선공**이 된다. (라운드 경계를 넘어서도 동일하게 적용된다 — 즉 "라운드 우승자"라는 별도 개념 없이, 마지막 턴 승자가 자연스럽게 다음 턴의 선공으로 이어진다)
* 선공 이후에는 §5.1의 고정 좌석 순서를 기준으로 시계방향으로 공개한다.
* 공개는 순차적이므로 늦게 내는 플레이어는 앞서 공개된 카드를 보고 판단할 수 있다. 다만 **턴의 승패 판정 자체는 그 턴에 나온 5장이 모두 모인 뒤 한 번에 계산**한다 (중간에 순서대로 확정되는 것이 아니라, 마지막 카드까지 포함한 합산으로 판정한다).

# 6. 승부 판정 (`resolveTurn`) — 확정

한 턴에서는 5명이 각자 카드 1장씩, 총 5장을 낸다. 판정은 다음 순서로 계산한다.

## 6.1 리버스 판정

그 턴에 나온 5장 중 리버스 카드(11, 22, 33)의 개수를 센다.

* **홀수** → 리버스 **활성**
* **짝수(0 포함)** → 리버스 **비활성** (원래 강약으로 복귀)

## 6.2 승자 결정

```
reverseActive == false (리버스 비활성):
  그 턴에 0 카드가 존재 → 0 카드를 낸 플레이어가 무조건 승리
                          (데스카드를 포함한 다른 모든 카드보다 위)
  0 카드가 없음:
    데스카드가 존재       → 데스카드를 낸 플레이어가 승리
    데스카드도 없음       → 가장 큰 숫자를 낸 플레이어가 승리

reverseActive == true (리버스 활성):
  데스카드가 존재         → 데스카드를 낸 플레이어가 무조건 승리
                          (0을 포함한 다른 모든 카드보다 위)
  데스카드가 없음         → 가장 작은 숫자를 낸 플레이어가 승리
                          (0이 있다면 0이 가장 강함)
```

정리하면:

* 데스카드는 원래 가장 강한 카드다. 단, **리버스가 비활성일 때는 0에게 진다.**
* 리버스가 **활성**이면 이 예외가 사라져서 **데스카드가 다시 (0을 포함해) 가장 강해진다.**
* 데스카드도 0도 없는 일반적인 경우, 리버스 비활성이면 큰 숫자가, 활성이면 작은 숫자가 이긴다.

## 6.3 동률 처리 — 0 카드가 여러 장 나온 경우 (확정)

그 턴의 승자가 0 카드를 낸 여러 명 중에서 갈리는 상황(0 카드 여러 장이 동시에 최강으로 판정된 경우)이라면, **그 턴에서 (혹은 1라운드라면 §5.1의 고정 좌석 순서 기준으로) 가장 먼저 0을 낸 플레이어**가 승리한다.

* 2라운드 이후의 턴: 실제 공개 순서(§5.3)에서 가장 먼저 0을 낸 사람.
* 1라운드: 동시 공개이므로 §5.1의 무작위 고정 좌석 순서를 기준으로 가장 앞선 사람.

(0을 제외한 모든 숫자는 덱에 정확히 1장씩만 있으므로, 0끼리의 동률 외에는 동률이 발생하지 않는다.)

# 7. 예측 (확정)

## 7.1 매 라운드 새로 예측

예측은 게임 시작 시 한 번만 하는 것이 아니라 **매 라운드마다 새로 선언**한다. 9라운드이므로 한 플레이어는 게임당 최대 9번의 예측을 한다. 각 라운드의 예측은 이전 라운드의 예측과 독립적이다.

## 7.2 예측 시점

그 라운드에 배분된 손패(R장)를 확인한 뒤, 그 라운드의 턴이 시작되기 전에 예측값을 결정하고 확정한다. 확정 후에는 변경할 수 없다.

## 7.3 예측 범위

라운드 R의 예측값은 그 라운드에서 실제로 나올 수 있는 승수 범위인 **0 ~ R** 중에서 고른다.

## 7.4 예측과 실제 결과 비교

라운드 R이 끝나면 그 라운드에서 실제로 이긴 턴의 수(A_R, 0~R)를 확인하고, 그 라운드의 예측값(P_R)과 정확히 일치하는지 확인한다. 일치하면 예측 성공, 다르면 실패다.

---

# 8. 히든 (확정)

* 각 플레이어는 **게임 전체에서 정확히 1회만** 히든을 사용할 수 있다.
* 히든은 9라운드 중 플레이어가 원하는 라운드에 자유롭게 사용할 수 있다.
* 히든을 사용한 라운드에도 예측 자체는 정상적으로(카드 승부 전에) 확정한다 — 히든은 "예측을 나중에 정하는 기능"이 아니라 **"이미 확정한 예측을 다른 플레이어에게 공개하지 않는 기능"**이다.
* 히든으로 숨겨진 예측값은 **해당 게임의 모든 라운드 결과가 전부 공개된 시점(9라운드 종료 후)**에 공개된다. 그 전까지는 다른 플레이어가 알 수 없다.
* 여러 플레이어가 같은 라운드에 각자의 히든을 사용하는 것은 허용된다 (히든은 개인별 자원이라 서로 간섭하지 않는다).
* 히든은 양도할 수 없고, 사용하지 않은 히든은 다음 게임으로 이월되지 않는다.

# 9. 점수 산식 (확정)

각 라운드 번호를 `R`, 그 라운드의 예측 승수를 `P`, 그 라운드의 실제 승수를 `A`라 한다.

```
scoreRound(P, A, R):
  if P == 0:
    A == 0 → +R
    A > 0  → -R
  else (P >= 1):
    P == A → +P × 2
    P != A → -(|P - A|) × 2
```

* `P >= 1`일 때는 라운드 번호 `R`이 점수에 영향을 주지 않는다 — 오직 예측값과 실제값의 관계로만 결정된다.
* `P == 0`일 때는 라운드 번호 `R` 자체가 점수의 크기가 된다 — 라운드가 진행될수록(후반 라운드일수록) 0승 예측의 성공/실패 점수 폭이 커진다.

## 9.1 최종 점수

```
FinalScore = Σ(R=1..9) scoreRound(P_R, A_R, R)
```

9개 라운드 각각의 점수를 모두 더한 값이 그 플레이어의 최종 점수다.

## 9.2 검증용 예시 (반드시 테스트로 재현)

**ROUND 1** (R=1): `0→0=+1`, `0→1=-1`, `1→1=+2`, `1→0=-2`, `1→2=-2`, `2→2=+4`, `2→0=-4`

**ROUND 5** (R=5): `0→0=+5`, `0→1=-5`, `0→3=-5`, `1→1=+2`, `1→3=-4`, `3→3=+6`

**ROUND 9** (R=9): `0→0=+9`, `0→1=-9`, `0→4=-9`, `2→2=+4`, `2→5=-6`, `5→5=+10`

---

# 10. 최종 순위 (확정)

9라운드 종료 후 최종 점수(`FinalScore`)가 가장 높은 플레이어가 승리한다.

**최종 점수가 동일한 플레이어들은 공동 등수로 처리한다. 별도의 타이브레이커는 적용하지 않는다.**

---

# 11. 한 라운드의 전체 진행 순서 (확정)

1. 라운드 시작 — 45장 전체를 다시 섞어 각 플레이어에게 R장씩 배분
2. 각 플레이어가 자신의 R장 손패 확인
3. 각 플레이어가 이번 라운드의 예측값(0~R) 결정
4. 히든 사용 여부 결정 (사용 가능 자원이 남아있는 플레이어만)
5. 히든이 아닌 플레이어의 예측 공개
6. R번의 턴 반복:
   1. 그 턴의 선공 결정 (1라운드는 동시공개라 선공 없음 / 2라운드부터는 직전 턴 승자)
   2. 순서대로(또는 1라운드는 동시에) 카드 공개
   3. §6의 판정 로직으로 그 턴의 승자 결정
   4. 승자의 그 라운드 누적 승수 +1
7. 그 라운드의 실제 승수(A_R) 확정
8. 예측(P_R)과 실제(A_R) 비교 → §9의 점수 산식으로 그 라운드 점수 계산
9. 다음 라운드로 이동 (9라운드 종료 시 게임 종료)

---

# 12. 공개/비공개 정보

## 공개 정보
* 현재 라운드/턴
* 각 플레이어의 (히든이 아닌) 예측값
* 이미 공개된 카드
* 각 턴/라운드의 결과
* 공개 점수
* 각 플레이어의 히든 사용 여부(사용했는지 여부는 공개되지만, 사용한 라운드의 예측값 자체는 게임 종료까지 비공개)

## 비공개 정보
* 각 플레이어의 아직 사용하지 않은 손패
* 히든으로 숨겨진 예측값 (게임 종료까지)

# 13. 핵심 규칙 요약

1. 5인 고정, 9라운드.
2. 라운드 R마다 카드 R장 배분, R번의 턴 진행 (매 라운드 45장 재셔플, 폐기 없음).
3. 매 라운드 새로 예측(0~R), 확정 후 변경 불가.
4. 히든은 플레이어당 게임 전체 1회, 원하는 라운드에 사용, 게임 종료 시 공개.
5. 1라운드는 동시공개, 2라운드부터는 직전 턴 승자가 선공 후 좌석 순서로 시계방향 공개.
6. 판정: 리버스 활성 여부(그 턴 리버스 카드 수의 홀짝)에 따라 큰/작은 숫자 승리가 뒤바뀌고, 0과 데스카드는 리버스 비활성/활성에 따라 서로의 우위가 뒤바뀐다.
7. 0 카드 동률은 먼저 낸 사람이 우선 (1라운드는 무작위 고정 좌석 순서 기준).
8. 점수 = `scoreRound(P, A, R)`를 9라운드 합산. `P≥1`: 성공 `P×2`/실패 `-|P-A|×2`. `P=0`: 성공 `+R`/실패 `-R`.
9. 최종 동점은 공동 등수 처리, 타이브레이커 없음.
