# 단어 마천루 (Word Skyscraper) — 완전 룰북 A to Z

> 주제가 공개되면 모두 동시에 그 주제의 단어를 쏟아내 **자기 탑**을 쌓는 2~8인 실시간 단어 게임.
> 단어 하나가 층이 되고, 라운드가 끝났을 때 **가장 높은 탑**이 그 라운드의 1등이다.
> 사전에 없는 단어는 버리지 않고 **다른 플레이어의 투표**로 인정 여부를 정한다.
>
> 로블록스의 "한국어 단어 쌓기"류 게임에서 착안했지만 규칙·이름·그림은 이 프로젝트의 오리지널이다
> (프로젝트 방침 `저작권, 상표권.md`). 이 문서가 앱 구현(`src/games/wordTower/`)의 기준이다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 실시간 단어 떠올리기 · 파티 |
| 인원 | **2 ~ 8명** (AI 봇으로 빈자리 채우기 가능, 사람 1명 + 봇도 가능) |
| 시간 | 라운드당 약 1분 30초, 한 판(5라운드) 약 8분 |
| 승리 | 라운드 1등(🏆)을 가장 많이 한 사람. 동점이면 전체 누적 층수 |
| 핵심 | 속도 경쟁이 아니다 — 같은 단어를 여러 명이 써도 모두 인정된다. **시간 안에 얼마나 많이·길게 떠올리느냐**만 겨룬다 |

## 2. 용어

| 용어 | 뜻 |
|---|---|
| 주제 | 라운드마다 공개되는 단어 범주 (예: 🍎 과일, 🐾 동물) |
| 탑 | 플레이어마다 하나씩 있는 단어 탑. 라운드마다 새로 쌓는다 |
| 층(블록) | 탑의 높이 단위. 단어 하나가 1~4층 (§6) |
| 확정 단어 | 게임 사전의 그 주제 목록에 있는 단어 — 즉시 층이 된다 |
| 보류 단어 | 사전에 없는 단어 — 반투명 층으로 올라가고, 라운드 끝 **심사 투표**로 결정 |
| 무너짐 | 심사에서 거절된 보류 단어. 그 층이 빠지고 벌점 1층 |

## 3. 게임 준비 (방장 설정)

| 설정 | 선택지 | 기본 |
|---|---|---|
| 인원 | 2 ~ 8명 | 4명 |
| 라운드 수 | 3 / 5 / 7 | 5 |
| 게임 버전 | 🏗️ 자유 쌓기(이 문서 §4~§12) / 🎯 정답 모으기(§15) | 자유 쌓기 |
| 주제 카테고리 | 🎲 전체 랜덤, 또는 카테고리 여러 개 선택(아래) | 전체 랜덤 |
| 쌓기 시간 | 30초 / 45초 / 60초 / 90초 | 자유 쌓기 60초 · 정답 모으기 45초 |

- 주제는 매 라운드 **고른 카테고리**(안 고르면 전체)의 주제 중에서 **겹치지 않게 무작위**로 뽑는다(시드 기반 — 모든 기기가 같은 순서).
- 고른 카테고리의 주제 수가 라운드 수보다 적으면 라운드 수를 그 주제 수로 줄인다(같은 주제 반복 없음).
- 카테고리 — 🏗️ 자유 쌓기: 🍎 먹거리(6) · 🐾 생물(5) · 🌍 장소·자연(4) · 🧑 사람·생활(5) · 📦 물건(5). 🎯 정답 모으기: 🔭 자연·과학(7) · 🗺️ 지리(5) · 🏯 한국 문화·역사(12) · 📚 상식·교과(14) · 📜 동양 사상·고전(7) · ⚽ 놀이·스포츠·군대(8). (괄호 = 주제 수, 앱 `categories.ts`)
- 인원이 모자라면 방장이 AI 봇(Lv.1~10)으로 채운다. "지금 시작"으로 정원보다 적게 시작할 수 있다.

## 4. 한 라운드의 흐름

1. **📣 주제 공개 (3초)** — 화면 가운데 주제가 크게 뜬다. 아직 입력은 막혀 있다.
2. **🏗️ 쌓기 (45/60/90초)** — 모두 동시에 단어를 입력한다. 한 번에 한 단어, 엔터(또는 [쌓기])로 제출.
   - 확정 단어는 바로 내 탑에 층으로 떨어진다.
   - 보류 단어는 반투명 층으로 올라간다.
   - **다른 사람이 쓴 단어는 보이지 않는다.** 보이는 것은 각자의 탑 높이(보류 층 포함)뿐이다 — 남의 단어를 베낄 수 없다.
3. **🗳️ 심사 (최대 25초, 보류 단어가 있을 때만)** — 모든 보류 단어를 한 화면에 모아 다른 플레이어가 인정(✅)/거절(❌)한다(§7).
4. **🏆 라운드 결과 (9초)** — 모든 사람의 단어가 공개되고, 층수 순위와 라운드 1등이 발표된다. 방장은 [다음 라운드]로 바로 넘길 수 있다.
5. 마지막 라운드가 끝나면 최종 결과(§9).

## 5. 단어 규칙

제출한 글자는 먼저 **띄어쓰기와 문장부호를 지운 뒤** 판정한다("아이스 크림" = "아이스크림").

| 판정 | 결과 |
|---|---|
| 한글 완성형 글자만, **1 ~ 8글자** | 통과 (아니면 입력이 막힘: 영어·숫자·자음만·9글자 이상 등) |
| 이번 판에서 **내가 이미 쓴 단어** | 막힘 (이전 라운드 포함). 다른 사람이 쓴 단어는 상관없음 |
| 금칙어(욕설) 포함 | 막힘 |
| 한 라운드에 단어 **30개**를 넘김 | 막힘 |
| 사전에 없는 단어가 이미 **보류 6개** | 막힘 (심사 부담 제한) — 사전에 있는 단어는 계속 낼 수 있다 |
| 이번 주제의 사전 목록에 있음 | **확정 단어** |
| 위를 다 통과했지만 사전에 없음 | **보류 단어** (다른 주제의 사전 단어도 여기에 해당) |

- 막힌 입력은 이유가 입력창 아래에 바로 표시되고, 벌점은 없다.
- 표기 변형(케익/케이크), 사투리, 복합어는 사전에 없으면 보류 → 투표로 결정된다.

## 6. 블록(층) 계산

- 단어 하나 = **글자 수만큼의 층, 최대 4층**.
  - 1글자 → 1층, 2글자 → 2층, 3글자 → 3층, 4글자 이상 → 4층.
  - 상한을 둔 이유: "아주아주큰빨간사과" 같은 늘려 붙이기로 이득을 보지 못하게.
- 탑 높이 = 확정 단어 층 + 인정된 보류 단어 층 − **거절된 단어 수 × 1** (0 밑으로는 내려가지 않음).
- 쌓기 중 표시되는 높이에는 보류 층이 포함된다(반투명).

---

## 7. 심사 투표 (사전에 없는 단어)

- **투표권**: 그 단어를 낸 사람을 뺀 모든 사람 플레이어. AI 봇과 봇이 대신 하는 자리는 기권한다.
- 각 보류 단어마다 ✅ 인정 / ❌ 거절 중 하나. 단어별로 따로 고르고, 바꿀 수 있다(마지막 선택이 유효).
- **판정**: 인정 표가 거절 표보다 **많으면 인정**. 동점이거나 아무도 투표하지 않으면 **거절**.
  - 그래서 사람이 혼자인 판(나머지가 모두 봇)에서는 보류 단어가 모두 거절된다 — 사전에 있는 단어로 승부해야 한다.
  - 2인 판에서는 상대 한 명이 판정한다(우정 플레이 전제).
- 투표를 할 수 있는 사람이 모두 모든 단어에 투표하면 25초를 기다리지 않고 바로 끝난다.
- 기준: "이 주제에 속하는, 실제로 쓰는 단어인가". 판단은 투표자의 몫이며 앱은 개입하지 않는다.
- 인정된 단어는 **그 판에서만** 유효하다. 공용 사전에 자동으로 추가되지 않는다(사전 오염 방지).

---

## 8. 라운드 순위와 동점

라운드 순위는 다음 순서로 가린다.

1. 탑 높이(층)가 높은 사람
2. 거절된 단어가 적은 사람
3. 인정된 단어 수(확정+인정)가 많은 사람
4. 그래도 같으면 **공동 1등** — 공동 1등은 모두 🏆을 받는다.

- 탑 높이가 0이면 1등이 될 수 없다(모두 0이면 그 라운드는 1등 없음).

---

## 9. 최종 승리와 연승

- **최종 순위**: 🏆 수 → 전체 라운드 누적 층수 → 그래도 같으면 공동 순위.
- **연승**: 라운드 1등을 연속으로 한 횟수. 화면에 🔥N연승으로 표시되고, 한 판의 최고 연승이 전적(/stats)에 남는다.

---

## 10. 특수 상황 판정 (FAQ)

- **같은 단어를 두 사람이 썼다** → 둘 다 인정. 속도 경쟁이 아니다.
- **보류 단어를 냈는데 같은 단어를 다른 사람도 보류로 냈다** → 단어마다 따로 심사한다(각자의 투표권 규칙이 다르므로).
- **쌓기 시간이 끝나는 순간에 낸 단어** → 방장 기기에 시간 종료가 처리되기 전에 도착한 것만 인정.
- **심사 중 나간 사람** → 그 사람의 표는 그때까지 낸 것만 센다. 그 사람의 보류 단어도 그대로 심사.
- **연결이 끊겼다** → 다른 사람들의 투표로 AI 봇이 대신할 수 있다(사이트 공통 규칙). 2라운드 연속으로 단어를 하나도 못 낸 사람도 투표 대상이 된다. 돌아오면 자리를 되찾을 수 있다.
- **주제와 상관있는지 애매한 단어**(예: 동물에 "공룡") → 사전에 없으면 투표로.

---

## 11. AI 봇

- 봇은 **사전의 그 주제 단어만** 쓴다(보류 단어를 거의 내지 않음). 심사에서는 기권.
- 레벨이 높을수록:
  - 단어를 더 빨리 낸다 (Lv.1 약 8초마다 → Lv.10 약 2.3초마다, 사람처럼 들쭉날쭉).
  - 아는 단어가 많다 (Lv.1 주제 사전의 40% → Lv.10 100%).
  - 3~4글자 단어를 더 고른다(층이 많이 오르는 단어).
- 낮은 레벨 봇은 가끔 **다른 주제의 단어**를 잘못 낸다(보류 단어가 되어 사람의 심사를 받는다).

## 12. 주제와 단어 사전

- 주제 25개, 주제마다 수십~백여 개의 흔한 명사(앱 `src/games/wordTower/words.ts`).
- "동물" 주제는 새·바다 생물·곤충 주제의 단어도 함께 인정한다.
- 작성 규칙: 한글 1~8글자 명사, 실존 상표·인물 제외, 주제 경계가 분명한 것.
- 사전에 빠진 단어 때문에 억울한 일이 없도록 심사 투표가 있다 — 자주 인정되는 단어는 나중에 사전에 추가한다.

## 13. 온라인 구현 명세

- **동기화**: 락스텝(docs/cloud-sync.md). 방장이 시드+옵션을 보내면 모든 기기가 같은 주제 순서를 만든다. 이후 `SUBMIT`/`VOTE`/`TIMEOUT`/`NEXT` 액션만 오간다. 단어 판정(사전·금칙어)은 결정적이라 모든 기기가 같은 결과를 낸다.
- **시간**: 각 기기가 단계(stage)가 바뀐 것을 본 시각부터 잰다. 시간이 다 되면 방장만 `TIMEOUT { stage }`를 보낸다.
- **심사 조기 종료**: 방장이 "투표권 있는 사람 모두가 모든 보류 단어에 투표했는지"를 보고 `TIMEOUT`을 앞당겨 보낸다.
- **3D 화면** (three.js + @react-three/fiber, 표시 전용):
  - 원형 무대 위에 플레이어 탑이 나란히 서고, 단어 하나가 색 블록 하나(층수만큼 두께)로 위에서 떨어져 쌓인다.
  - 내 단어는 블록 앞면에 글자가 보이고, 남의 단어는 라운드 결과 전까지 무늬만 보인다.
  - 보류 블록은 반투명하게 깜빡이고, 심사 결과 인정되면 금빛으로 굳고 거절되면 굴러떨어진다.
  - 탑이 높을수록 살짝 흔들린다(정해진 애니메이션, 물리엔진 없음 — 모든 기기에서 같은 모습).
  - 현재 1등 탑 꼭대기에 왕관이 뜨고, 카메라는 가장 높은 탑에 맞춰 자동으로 물러난다.
  - WebGL이 없는 기기는 2D 막대 화면으로 자동 전환, ⚙에서 3D/2D 전환 가능.
- **입력**: 한글 조합 중 엔터를 눌러도 마지막 글자가 빠지지 않도록 입력창의 실제 값을 읽어 제출한다.

## 14. 빠른 요약 카드

```
📣 주제 공개 → 🏗️ 60초 동안 주제 단어를 마구 입력 → 🗳️ 사전에 없는 단어 심사 → 🏆 가장 높은 탑이 1등
• 단어 1개 = 글자 수만큼 층 (최대 4층)
• 남의 단어는 결과 때까지 안 보임 · 같은 단어 써도 OK · 내가 쓴 단어는 다시 못 씀
• 사전에 없으면 반투명 보류 → 다른 사람 과반 ✅면 인정, 아니면 무너지고 −1층
• 동점: 거절 적은 사람 → 단어 많은 사람 → 공동 1등
• 최종: 🏆 많은 사람 → 누적 층수
```

## 15. 🎯 정답 모으기 모드 (추가 버전)

방 만들기에서 **게임 버전**으로 고른다. 동시 입력·라운드 1등·🏆·연승은 같고, 주제·공개 방식·점수가 다르다.

| 항목 | 🏗️ 자유 쌓기 | 🎯 정답 모으기 |
|---|---|---|
| 주제 | 정답이 끝없는 주제 (과일, 동물…) | **정답이 4~10개로 정해진 주제** (계절 4개, 요일 7개, 태양계 행성 8개…) |
| 남의 답 | 라운드 결과 때까지 비공개 | **실시간 공개** — 화면 아래 "📢 실시간 기록"에 누가 무엇을 냈는지(정답·오답) 모두에게 보인다 |
| 같은 단어 | 여러 명이 써도 모두 인정 | **중복 불가, 선착순** — 정답은 먼저 낸 한 사람만 차지 |
| 정답 판정 | 사전 + 사전에 없으면 심사 투표 | 정답 목록이 전부 — **심사 없음** |
| 맞으면 | 글자 수만큼 층(최대 4층) | 먼저 차지하면 **2층** (글자 수 상관없음) |
| 틀리면 | (사전에 없을 때) 심사에서 거절되면 −1층 | 바로 **−1층** (블록이 굴러떨어짐) |
| 라운드 끝 | 시간 종료 | 시간 종료 **또는 정답이 모두 차지되는 순간** |
| 보너스 | 없음 | 한 사람이 정답을 **혼자 전부 차지하면 +3층** (🧹 싹쓸이, 금색 블록) |

- **같은 답의 다른 표기**도 정답으로 친다: "월"="월요일", "녹색"="초록", "북미"="북아메리카" 등(앱 `closedTopics.ts`의 `aliases`). 띄어쓰기·문장부호는 무시.
- **선착순 판정**: 방장 기기에 먼저 도착한 답이 차지한다(모든 기기가 같은 순서로 처리). 이미 차지된 정답은 입력이 막히고(벌점 없음), 거의 동시에 보내 한발 늦은 경우 실시간 기록에 "⏱ 한발 늦음"으로만 남는다(0층, 벌점 없음).
- 내가 차지한 정답을 다시 쓰거나(다른 표기 포함) 같은 오답을 두 번 쓰면 입력이 막힌다(벌점 없음).
- 중복 금지는 **그 라운드 안에서만** — 다른 라운드 주제에 같은 정답이 있을 수 있다(계이름·윷놀이의 "도").
- 쌓기 중 정답 칸이 보인다: 차지된 정답은 단어와 차지한 사람 색 점, 남은 정답은 번호 빈칸. 3D 탑 블록에도 모두의 단어가 보인다.
- 결과 때 아무도 못 찾은 정답까지 전부 공개되고, 그 주제에 대한 **짧은 설명 문구**(💡)가 함께 나온다(예: 계절 — 봄·여름·가을·겨울, 우리나라는 사계절이 뚜렷한 기후).
- 주제 공개 때와 화면 위쪽에 **맞춰야 할 정답 수**("🎯 정답 4개")가 크게 표시된다.
- 오답 벌점이 있어서 마구 찍기는 손해다. 그래서 오답에 입력 제한(보류 6개)은 없다.
- 봇: 아직 안 차지된 정답 중 아는 것(레벨에 따라 30~100%)만 낸다. 낮은 레벨은 가끔 틀린 답.
- **인원에 따라 주제 크기 제한**: 사람이 많을수록 나눠 가질 정답이 많아야 하므로, 인원(봇 포함)별로 정답 수가 이만큼 이상인 주제만 나온다 — 2~3명 4개 · 4명 5개 · 5명 6개 · 6명 7개 · 7~8명 8개. 정답이 적은 주제는 인원이 적을 때만 나온다. 고른 카테고리에 조건을 만족하는 주제가 라운드 수보다 적으면, 남은 주제 중 정답이 많은 것부터 채운다.
