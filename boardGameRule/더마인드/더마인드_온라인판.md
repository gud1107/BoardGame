# 📡 텔레파시 (가칭) — 온라인 전용 룰북

> 「더 마인드」의 핵심(말없이 숫자를 오름차순으로 내는 협력 게임)을 **온라인 환경에 맞게 처음부터 다시 설계한 규칙**입니다.
> 원작 규칙 정리는 같은 폴더의 [더마인드.md](더마인드.md)에 있습니다. 이 문서가 **실제 구현 기준**입니다.
> 화면에는 원작 이름·토끼·수리검을 쓰지 않습니다. 이 문서의 이름·테마는 모두 가칭입니다.

이 문서대로 만들되, 첫 출시에서 아래만 다르게 했습니다.

| 잠수 (§10-1) | 탭 숨김 15초 / 동기화 60초 | **동기화 단계에서 60초 동안 아무 입력 없음**만 감지 |
| 채팅 (§9) | 진행 중 잠금, 쉬는 시간만 허용 | 이 게임엔 **채팅 자체가 없음** (잠글 필요 없음) |
| 봇 난이도 (§13-3) | 3단계 | 다른 게임과 같은 **Lv.1~10** (빠른 시작은 쉬움 3 / 보통 6 / 어려움 9) |
| 모드 (§14) | 일반·오늘의 도전·연습·블라인드 | **일반 + 연습 + 봇과 바로 하기**만. 오늘의 도전·블라인드·랭킹은 다음 단계 |
| 숨은 정보 | — | 방장이 전체 상태를 보내므로 개발자 도구로 남의 카드를 볼 수는 있음 (다른 게임과 같은 수준, 협력 게임이라 영향 작음) |

봇 시뮬레이션 결과 (같은 레벨 봇끼리 150판, 승률): Lv.5 0~4% · Lv.8 63~87% · Lv.10 99~100%.
봇은 모두 같은 "숫자 간격 × 0.23초" 박자를 써서 서로 잘 맞고, 사람이 그 박자에 맞추는 구조입니다.

## 0. 왜 다시 만들었나 — 온라인에서 생기는 문제와 해결

| 원작을 그대로 옮겼을 때 생기는 문제 | 온라인판 해결책 |
|---|---|
| 서로 얼굴이 안 보여서 "누가 곧 낼 것 같은지" 느낄 수 없다 | **누르고 있기로 내기** + 상대 자리에 **"뻗는 중" 빛** 표시 (§5-2) |
| 사람마다 인터넷 속도가 달라 거의 동시에 낸 카드의 순서가 운으로 갈린다 | **0.25초 관용 판정**: 이 시간 안에 겹치면 낮은 카드를 먼저 낸 것으로 처리 (§5-4) |
| 시간 감각을 맞출 공통 기준이 없다 (각자 화면이 다르게 보임) | 모두에게 똑같이 보이는 **흐름 시계** (§5-1) |
| 실수를 사람이 알아차려야 한다 | 서버가 **즉시 자동 판정** (§6) |
| 채팅·이모지·음성으로 쉽게 정보를 흘릴 수 있다 | 레벨 진행 중에는 **채팅·이모지 잠금**. 정해진 신호만 사용 가능 (§9) |
| 잠수·탭 이탈 한 명 때문에 판 전체가 멈춘다 | 접속 감지 → **자동 일시정지** → 재접속 대기 → 봇 대체 투표 (§10) |
| 손을 올리는 "집중"을 화면으로 대신할 방법이 없다 | **모두 함께 누르고 있기** + 서버 기준 3초 카운트다운 (§4) |
| 점수가 없어서 다시 할 동기가 약하다 | **점수·랭킹·오늘의 도전(모든 팀이 같은 덱)·리플레이 타임라인** (§11, §12) |
| 사람을 모으기 어렵다 | **봇과 함께하는 혼자 하기**. 봇이 빈자리를 채움 (§13) |

| 항목 | 내용 |

| 장르 | 실시간 완전 협력 / 타이밍 |
| 인원 | **2~6인** (사람 1명 + 봇 가능) |

**핵심 규칙 한 줄:** 각자 숫자 카드(1~100)를 들고, 서로 아무 정보도 주고받지 않은 채, **팀 전체 카드를 작은 수부터 한 장씩** 가운데 더미에 쌓습니다. 차례 순서는 없고, 누구든 원할 때 냅니다.

## 3. 게임 준비 (자동)

### 3-1. 인원별 설정

| 인원 | 레벨 | 시작 하트 | 시작 ⚡ | 마지막 레벨에 쓰는 카드 수 |
|---|---|---|---|---|
| 2인 | 1~12 | 2 | 1 | 24장 |
| 3인 | 1~10 | 3 | 1 | 30장 |
| 4인 | 1~8 | 4 | 1 | 32장 |
| 5인 | 1~7 | 5 | 1 | 35장 |
| 6인 | 1~6 | 5 | 1 | 36장 |

- 2~4인은 원작 수치 그대로입니다. 5~6인은 온라인판에서 새로 추가했으며, 출시 전 봇 시뮬레이션으로 난이도를 조정합니다 (§15).
- 최대치: **하트 5, ⚡ 3**. 넘치는 보상은 사라집니다.

### 3-2. 섞기와 배분

- 매 레벨 시작마다 서버가 카드 100장을 **시드 기반으로 섞어** 1인당 N장씩 나눕니다.
- 섞은 결과는 서버(방장)만 알고, 각 플레이어는 **자기 카드만** 받습니다. 다른 사람의 카드는 다른 사람 화면에 절대 보내지 않습니다.
- 내 카드는 자동으로 오름차순 정렬됩니다.

## 4. 동기화 (레벨 시작 의식)

1. 카드를 받으면 화면에 **🖐 동기화 버튼**이 뜹니다.
2. 각자 버튼을 **누르고 있습니다.** 누르고 있는 사람의 자리에는 🖐가 켜집니다.
3. **모든 사람이 동시에 누르고 있으면** 서버 기준 **3초 카운트다운**(3 · 2 · 1)이 시작됩니다.
4. 카운트다운 중 누군가 손을 떼면 카운트다운이 취소되고 2번으로 돌아갑니다.
5. 카운트다운이 끝나면 **레벨 시작**. 흐름 시계가 0초부터 돌기 시작합니다.

- 봇은 사람이 누르기 시작하면 0.3~1초 안에 따라 누릅니다.
- 모바일 편의: 누르고 있기가 불편한 경우를 위해 **설정에서 "탭으로 켜고 끄기" 방식**도 고를 수 있습니다.
- 동기화 단계에는 시간 제한이 없습니다. 단, 60초 동안 아무 반응이 없는 사람은 잠수로 처리합니다 (§10).

## 5. 카드 내기

### 5-1. 흐름 시계

- 화면 가운데, 신호 더미 둘레에 **흐름 시계**(차오르는 원형 게이지 + 초 단위 숫자)를 표시합니다.
- **마지막 카드가 나온 순간부터 지난 시간**을 보여 주며, 카드가 나올 때마다 0으로 돌아갑니다.
- 모든 사람의 시계는 **서버 시간에 맞춰** 똑같이 흐릅니다 (접속할 때 서버와 시간 차이를 측정해 보정).
- 이것이 온라인판의 "공통 박자"입니다. 이 시계를 기준으로 각자 "몇 초쯤 지나면 내 차례"를 감으로 맞춥니다.
- 시계는 **시간만** 보여 주며 숫자를 세는 다른 기능은 없습니다 (§9 금지 전략과 구분).

### 5-2. 누르고 있기로 내기

- 화면 아래에 **내 가장 낮은 카드 1장**이 크게 표시됩니다. 내는 버튼은 이 카드 하나뿐입니다. 높은 카드를 먼저 내는 것은 아예 불가능합니다.
- 카드를 **0.6초 동안 누르고 있으면** 게이지가 다 차면서 카드가 나갑니다.
- 누르고 있는 동안 **다른 사람 화면의 내 자리에 "뻗는 중" 빛**이 켜집니다. 원작에서 테이블 위로 손을 뻗는 모습이 보이는 것과 같은 역할입니다. 숫자는 드러나지 않습니다.
- 0.6초가 되기 전에 손을 떼면 **취소**됩니다. 상대 화면의 빛도 꺼집니다.
- 같은 사람이 연속으로 여러 장을 낼 수 있습니다 (한 장 나갈 때마다 다음 카드가 다시 0.6초 누르기).

#### 취소 남용 방지

- "뻗었다 말았다"를 반복하는 것은 신호 보내기가 될 수 있습니다.
- 한 레벨에서 **취소 3회까지** 자유롭습니다. 4번째부터는 취소한 뒤 **2초 동안 다시 누를 수 없습니다.**
- 뻗는 중 빛은 **0.2초 이상** 누른 뒤에만 다른 사람에게 보입니다 (실수로 스친 터치는 드러나지 않음).

### 5-3. 카드가 나간 뒤

- 신호 더미 맨 위에 카드가 크게 놓이고, 직전 3장은 작게 옆에 남습니다.
- 카드를 낸 사람 자리에 짧은 빛 효과가 나타납니다.
- 효과음 높이가 숫자에 비례합니다 (1 = 낮은 음, 100 = 높은 음). 화면을 안 봐도 진행 상황을 알 수 있습니다.
- 모든 사람의 **남은 카드 장수**는 항상 공개됩니다 (원작에서도 손에 든 장수는 보이므로).

### 5-4. 0.25초 관용 판정 (인터넷 지연 보정)

온라인에서는 거의 동시에 낸 두 카드의 도착 순서가 인터넷 속도에 따라 바뀔 수 있습니다. 이 운을 없애기 위해:

- 서버가 카드 X를 받은 뒤 **0.25초 안에** 그보다 **낮은** 카드 Y가 도착하면, **Y를 먼저 낸 것으로 순서를 바로잡습니다.** 실수가 아닙니다.
- 그래서 서버는 카드를 받으면 **0.25초 동안 확정을 미뤘다가** 화면에 공개합니다. 그 사이 낸 사람 화면에는 바로 "보냄" 효과를 보여 줘서 느리다는 느낌이 들지 않게 합니다.
- 0.25초가 지나서 도착한 낮은 카드는 원작과 같이 **실수**입니다.
- 이 규칙은 **사람이 판단하는 "동시"를 너그럽게 봐주는 것**입니다. 원작 테이블에서 두 손이 거의 같이 나오면 낮은 카드를 아래에 깔아 주는 것과 같습니다.

## 6. 실수 (자동 판정)

### 6-1. 실수 조건

카드 X가 **확정되는 순간**(§5-4 관용 시간이 끝난 뒤), 누구의 손에든 **X보다 낮은 카드**가 남아 있으면 실수입니다. 서버가 즉시 판정하므로 누군가 알아차릴 필요가 없습니다.

### 6-2. 실수 처리 (자동 연출, 약 3초)

1. **정지**: 모든 입력이 잠기고 화면이 잠깐 멈춥니다.
2. **공개**: X보다 낮은 카드를 가지고 있던 모든 사람의 해당 카드가 뒤집혀 드러납니다.
3. **버림**: 드러난 카드는 신호 더미가 아닌 **버림 줄**로 날아갑니다. X는 더미에 그대로 남습니다.
4. **하트 -1**: 실수 한 번에 낮은 카드가 몇 장 나왔든 하트는 **1개만** 깨집니다.
5. **재동기화**: 하트가 남아 있으면 자동으로 §4 동기화 단계로 들어갑니다. 모두 다시 누르고 있어야 레벨이 이어집니다. 레벨은 처음부터 다시 하지 않습니다.

- 연출은 "누가 너무 빨리 냈는가"가 아니라 **"드러난 낮은 카드"** 중심으로 보여 줍니다. 누군가를 탓하는 분위기를 만들지 않기 위해서입니다.
- 버림 줄은 레벨이 끝날 때까지 화면 한쪽에 계속 보입니다 (이미 나온 숫자를 알 수 있는 공개 정보).

### 6-3. 패배

- 하트가 0개가 되는 순간 **즉시 패배**. 남은 모든 카드가 공개되며 결과 화면으로 넘어갑니다.

## 7. 레벨 통과와 보상

### 7-1. 통과

- 모든 사람의 손이 비면 (낸 카드 + 실수로 버린 카드 + ⚡로 버린 카드 포함) 레벨 통과입니다.
- 짧은 통과 연출 → 보상 지급 → **레벨 사이 쉬는 시간**(§9-2) → 다음 레벨 카드 배분.

### 7-2. 보상 (원작과 같음)

| 통과한 레벨 | 보상 |
|---|---|
| 2 | ⚡ +1 |
| 3 | ❤️ +1 |
| 5 | ⚡ +1 |
| 6 | ❤️ +1 |
| 8 | ⚡ +1 |
| 9 | ❤️ +1 |

- 하트 5개, ⚡ 3개가 최대이며 넘치는 보상은 사라집니다.
- 마지막 레벨을 통과하면 보상 없이 바로 승리입니다.

## 8. ⚡ 번뜩임

### 8-1. 제안과 투표

1. 레벨 진행 중 누구든 **⚡ 버튼**을 누르면 제안이 시작됩니다.
2. 제안이 시작되면 **카드 내기가 일시 정지**되고 흐름 시계도 멈춥니다. (제안 도중에 카드가 나가서 생기는 혼란 방지)
3. 모든 사람 화면에 **찬성 / 반대** 버튼과 **8초 제한 시간**이 뜹니다. 제안한 사람은 자동으로 찬성입니다.
4. **전원 찬성**이면 바로 발동. 한 명이라도 반대하거나 8초가 지나면 취소됩니다.
5. 취소되면 §4 동기화 없이 1초 카운트다운 후 바로 이어서 진행합니다. 흐름 시계는 멈췄던 시간부터 다시 흐릅니다.

### 8-2. 발동

- ⚡ 1개를 쓰고, **모든 사람이 각자 가장 낮은 카드 1장**을 동시에 공개해 버림 줄로 보냅니다.
- 손에 카드가 없는 사람은 공개할 것이 없습니다.
- 발동 후 모든 손이 비면 레벨 통과입니다.
- 손이 남아 있으면 자동으로 §4 동기화 단계로 들어갑니다.

### 8-3. 남용 방지

- ⚡가 0개일 때는 버튼이 비활성화됩니다.
- 취소된 제안 뒤에는 **10초 동안 누구도 다시 제안할 수 없습니다** (일시 정지를 반복해 게임을 방해하는 것 방지).

## 9. 의사소통 규칙

### 9-1. 레벨 진행 중 (동기화 시작 ~ 레벨 통과)

| 사용 가능 | 잠김 |
|---|---|
| 🖐 동기화 버튼 | 채팅 |
| ⚡ 번뜩임 제안·투표 | 이모지·감정 표현 |
| 카드 누르고 있기 (뻗는 중 빛) | 닉네임 변경 |
| 🖐 레벨 도중 재동기화 요청 (§9-3) | |

- 관전자 채팅도 레벨 진행 중에는 잠깁니다.
- 음성 통화 같은 게임 밖 소통은 막을 수 없습니다. 방 만들기 화면에 "숫자를 말하지 않는 게 이 게임의 전부예요" 안내를 띄웁니다.

### 9-2. 레벨 사이 쉬는 시간

- 레벨이 끝나면 **최대 20초 쉬는 시간**이 있습니다. 이때는 채팅과 이모지를 쓸 수 있습니다.
- 쉬는 시간에는 방금 레벨의 **미니 타임라인**(§12)을 보여 줍니다.
- 모든 사람이 "준비" 버튼을 누르면 20초를 기다리지 않고 바로 다음 레벨 카드가 배분됩니다.
- 다음 레벨 카드가 배분되는 순간 채팅이 다시 잠깁니다.

### 9-3. 레벨 도중 재동기화

- 진행 중 누구든 **🖐 버튼**을 누르면 카드 내기가 일시 정지되고 §4 동기화 단계로 들어갑니다.
- 남용 방지: 한 사람이 레벨당 **2회**까지 요청할 수 있습니다. 실수 후 자동 재동기화는 이 횟수에 포함되지 않습니다.

### 9-4. 금지 전략 (안내만, 강제 없음)

- "흐름 시계 1초 = 숫자 몇" 같은 **미리 짠 카운팅 약속**은 게임 정신에 어긋납니다. 방 만들기 화면의 안내에만 적고, 시스템으로 막지는 않습니다.

## 10. 접속 끊김 · 잠수

### 10-1. 감지

다음 중 하나면 **"연결 불안정"** 으로 봅니다.
- 접속이 끊김 (presence 이탈)
- 탭을 숨긴 채 15초 이상 지남
- 동기화 단계에서 60초 동안 아무 입력이 없음

### 10-2. 처리

1. 레벨 진행 중이면 **즉시 일시 정지**. 해당 자리에 "연결 대기 중" 표시. 흐름 시계도 멈춥니다.
   (이 사람이 가장 낮은 카드를 들고 있을 수 있어서, 멈추지 않으면 다른 사람들이 실수로 몰립니다.)
2. **20초 재접속 대기**. 돌아오면 §4 동기화부터 다시 이어갑니다.
3. 20초가 지나면 기존 게임들과 같은 방식의 **봇 대체 투표**를 띄웁니다. 통과하면 봇이 그 자리의 카드를 이어받고 §4 동기화부터 다시 시작합니다.
4. 봇이 대신하던 자리에 원래 사람이 돌아오면, 다음 동기화 단계에서 자리를 돌려받습니다.

### 10-3. 중간 참가

- 게임이 시작된 뒤에는 새로 참가할 수 없습니다. 관전만 가능합니다.

## 11. 점수와 기록

원작에는 점수가 없지만, 다시 할 동기를 주기 위해 온라인판에는 점수를 둡니다. 승패 판정은 원작과 같고, 점수는 **기록용**입니다.

### 11-1. 점수 계산

| 항목 | 점수 |
|---|---|
| 레벨 통과 | 레벨 번호 × 100 (레벨 5 통과 = 500) |
| 실수 없이 통과한 레벨 | +50 (레벨마다) |
| 최종 승리 | +500 |
| 승리 시 남은 하트 | 하트 1개당 +100 |
| 승리 시 남은 ⚡ | ⚡ 1개당 +50 |

- 시간은 점수에 넣지 않습니다. 빨리 내도록 압박하면 이 게임의 "기다림"이 망가지기 때문입니다.
- 기록은 **인원수별로 따로** 저장합니다 (2인 기록과 4인 기록은 난이도가 다름).

### 11-2. 통계 · 업적

- 승패 통계와 업적 시스템에 연결합니다.
- 업적 예시:
  - 첫 승리
  - 하트를 하나도 잃지 않고 승리
  - ⚡를 하나도 쓰지 않고 승리
  - 한 레벨에서 1과 100이 모두 나온 레벨 통과
  - 0.25초 관용 판정으로 실수를 피한 순간 10회
  - 오늘의 도전 7일 연속 참가

## 12. 리플레이 타임라인

온라인이라서 가능한 기능입니다. 팀의 박자를 서로 맞춰 가는 데 쓰입니다.

- 레벨이 끝나면 (쉬는 시간, 결과 화면) **가로 타임라인**을 보여 줍니다.
  - 가로축: 레벨 시작부터 지난 시간
  - 점: 각 카드가 나온 시각과 숫자, 낸 사람 색깔
  - 실수 지점은 빨간 표시, 그때 드러난 낮은 카드도 함께 표시
- 레벨이 끝난 뒤에는 **모든 사람의 처음 손패**를 공개합니다 ("아, 네가 41을 들고 있었구나").
- 결과 화면에서는 레벨별 타임라인을 넘겨 볼 수 있습니다.
- 정보는 레벨이 끝난 뒤에만 공개되므로 진행 중인 게임에는 영향이 없습니다.

## 13. 봇

### 13-1. 기본 동작

- 봇도 **자기 카드만** 압니다. 다른 사람의 카드는 보지 않습니다.
- 봇이 카드를 내기까지 기다리는 시간의 기본 공식:
  - `대기 시간 = (내 가장 낮은 카드 − 더미 맨 위 숫자) × 박자 + 흔들림`
  - 박자는 남은 전체 카드 수와 남은 숫자 범위에 따라 조정 (남은 카드가 많을수록 숫자 간격이 촘촘하므로 박자를 줄임)
  - 버림 줄과 ⚡로 공개된 숫자를 반영해 "아직 남아 있을 수 있는 숫자"만으로 계산
- 봇도 0.6초 누르고 있기를 똑같이 거치며, 뻗는 중 빛도 똑같이 보입니다.
- 사람의 뻗는 중 빛을 보면 잠깐 멈칫합니다 (상대가 먼저 낼 수 있게 양보).

### 13-2. 그 밖의 판단

- ⚡ 투표: 남은 카드 수가 많고 다음 카드 간격이 애매할 때 찬성. 제안은 하지 않음 (사람이 주도).
- 동기화: 사람이 누르면 따라 누름.

### 13-3. 난이도

| 단계 | 흔들림 | 설명 |
|---|---|---|
| 쉬움 | 크게 | 실수를 자주 함. 처음 하는 사람과 비슷 |
| 보통 | 중간 | 익숙한 사람 수준 |
| 어려움 | 작게 | 박자가 정확함. 사람이 봇에 맞추기 좋음 |

- 봇의 실력이 너무 좋으면 사람이 할 일이 없어지므로, 어려움 봇도 **완벽하지는 않게** 맞춥니다.

### 13-4. 혼자 하기

- 사람 1명 + 봇 1~5명으로 바로 시작할 수 있습니다.
- 봇만 있는 방의 기록은 랭킹에 넣지 않고 개인 기록으로만 남깁니다.

## 14. 모드

| 모드 | 내용 | 랭킹 |
|---|---|---|
| **일반** | 이 문서의 기본 규칙 | O |
| **오늘의 도전** | 날짜별 고정 시드로 **모든 팀이 같은 손패**를 받음. 하루 1회 기록. 같은 문제를 다른 팀은 어떻게 풀었는지 비교 | O (일별) |
| **연습** | 하트 무한, ⚡ 무한, 레벨 선택 가능 | X |
| **블라인드** (숙련자용) | 카드가 뒷면으로 쌓여 진행 중에는 숫자가 안 보임. 레벨 끝에 한꺼번에 뒤집어 확인하고, 순서가 한 곳이라도 틀리면 하트 -1. ⚡ 사용 불가. 0.25초 관용 판정은 그대로 적용 | O (별도) |

- 오늘의 도전은 인원수별로 시드가 다릅니다.
- 첫 출시 범위: **일반 + 연습 + 혼자 하기**. 오늘의 도전과 블라인드는 2차 출시로 미룰 수 있습니다.

## 15. 균형 검증 계획 (출시 전)

- 봇끼리 대전시키는 시뮬레이션으로 인원별 **최종 승률**과 **평균 도달 레벨**을 측정합니다.
- 목표 기준 (보통 봇 기준): 2~4인 승률 **20~35%**, 5~6인도 같은 범위에 들도록 레벨 수와 시작 하트를 조정합니다.
- 0.25초 관용 시간과 0.6초 누르기 시간은 실제 플레이 테스트로 조정합니다.
- 레벨 진행 로직은 Math.random을 쓰지 않고 시드 기반으로만 섞습니다 (오늘의 도전 재현성 + 다시 보기용).

## 17. 진행 예시 (3인, 레벨 2)

- 시작: 하트 3, ⚡ 1 · 손패: 나 [8, 71] / 민 [33, 35] / 봇 [49, 90]

1. 모두 🖐를 누르고 있음 → 3·2·1 → 시작. 흐름 시계 0초.
2. 2초쯤, 내가 8을 누르고 있음 → 다른 사람 화면에 내 자리 "뻗는 중" 빛 → 0.6초 후 **8** 확정. 시계 0으로.
3. 9초쯤 민이 **33**, 곧바로 **35**를 연달아 냄.
4. 5초 뒤 봇이 **49**를 냄.
5. 나는 71을 들고 기다리는 중. 봇이 90을 누르기 시작하고, 거의 같은 순간 나도 71을 누름.
6. 서버에 90이 먼저 도착, 0.2초 뒤 71 도착 → **0.25초 관용 판정**으로 71이 먼저 낸 것으로 처리 → 실수 아님. 더미: 49 → 71 → 90.
7. 모든 손이 빔 → 레벨 2 **통과**, 실수 없음 보너스. 보상 ⚡ +1 (⚡ 2개).
8. 쉬는 시간: 타임라인에서 "8, 33, 35, 49, 71, 90"이 찍힌 시각을 보며 채팅 → 모두 준비 → 레벨 3 배분.

(만약 71이 0.4초 늦게 도착했다면 → 실수 → 71 공개·버림, 하트 3 → 2, 손이 비었으므로 레벨 2는 통과하되 실수 없음 보너스는 없음.)
