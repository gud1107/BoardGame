# 변신 숨바꼭질 (Morph & Seek)

> 자체 창작 룰. 구현: `src/games/morphHide/` (id `morph-hide`). 수치는 전부 `data.ts`에 있고, 아래 표는 거기서 옮겼다 — 바꾸면 이 표도 같이 고칠 것.
> 출발점: 2026-11-05 사용자 요청 "카스 + 메챠카멜레온 + 롤 증강처럼". 턴제 [한밤의 숨바꼭질](../숨바꼭질/숨바꼭질.md)은 그대로 두고 **별도 게임**으로 만들었다(사용자 선택).

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 인원 | 2~8명 (빈자리는 AI 봇 Lv.1~10) · 6명부터 술래 2명 |
| 시간 | 라운드당 약 1분(고르기·숨기) + 술래 시간 3·5·7분 |
| 장르 | 실시간 3D 숨바꼭질 (프롭헌트류) |
| 목표 | 라운드마다 술래가 바뀌고, 점수 합이 가장 높은 사람이 승리 |
| 맵 | 3D 저택(1층·2층·다락·지붕) + 뒷골목 + 앞마당 + 도로·건널목 + 공원 |

## 2. 라운드 진행

1. **🎴 변신 고르기 (15초)** — 숨는 사람마다 카드 3장(살아 있는 것 1장 + 물건 1장 + 아무거나 1장). 롤 증강처럼 하나를 고른다. **안 고르면 랜덤**. 다시 뽑기 1번.
2. **🙈 숨기 (30초)** — 술래는 기지(마당 기둥)에서 눈을 가린다(화면이 까맣다). 숨는 사람은 변신한 모습으로 돌아다니며 숨는다.
3. **👁️ 술래 시간 (3·5·7분)** — 술래가 찾는다. 모두 잡히거나, 시간이 끝나거나, 술래 체력이 전부 0이 되면 라운드 끝.
4. **📋 결과 (7초)** — 누가 무엇으로 변신했고 어떻게 됐는지 공개.

## 3. 변신 (`DISGUISES`)

| 종류 | 변신 | 특징 |
| --- | --- | --- |
| 사람 | 🚶 행인 | 건널목·인도·공원을 걷는 NPC 행인 6명 틈에 섞인다. 신호를 안 지키거나 뛰면 수상 |
| 동물 | 🐕 강아지 · 🐈 고양이 | 마당·공원의 NPC 강아지·고양이처럼 뛰고 쉰다 |
| 술래 위장 | 👮 술래인 척 | 술래와 같은 옷의 **점검원**. NPC 점검원 2명이 집 안팎을 돌며 **손을 앞으로 내밀고 점검**한다 — 그 동작을 흉내 내야 한다 |
| 기계 | 🤖 로봇 청소기 | 거실을 빙빙 도는 NPC 청소기와 같은 모양 |
| 물건 | 🗑️ 쓰레기통 · 🧯 소화전 · 🪑 벤치 · 🚧 고깔 · 📮 우체통 · 🥤 자판기 · 📦 나무 상자 · 🪑 의자 · 🛢️ 드럼통 · 🧙 정원 난쟁이 · 🪴 화분 · 🧺 빨래 바구니 · 🧸 장난감 상자 · 🧳 트렁크 · 🕴️ 마네킹 · 🧥 코트 걸이 · 🧺 세탁기 · 📦 상자 더미 · 🖋️ 책상 | 가만히 있으면 진짜와 똑같다. 움직이면 들썩여서 티가 난다 |

- **원래 없던 것도 생긴다**: 판마다 맵 42곳 중 30곳에 물건 16종이 골고루 새로 깔린다(`buildFillers`, 시드로 모든 기기가 똑같이). 그래서 어떤 물건으로 변신해도 진짜가 섞여 있다.
- **🔄 자세 바꾸기 (C)**: 물건 = 기본/90°/뒤돌기/270°/넘어뜨리기, 사람 = 서기/폰 보기/앉기/쪼그려 앉기/눕기, 강아지 = 서기/앉기/엎드리기/뒹굴기, 고양이 = 서기/식빵 굽기/기지개, 점검원 = 서기/점검하기/무전하기.
- **👯 분신 (G)**: 내 바로 뒤에 똑같은 모양·자세의 가짜를 세운다. 라운드당 2개(+보물 상자). 살아 있는 모양이면 그 근처를 어슬렁거린다. 술래가 치면 엉뚱한 것 판정.

## 4. 술래 무기 (`WEAPONS`, `weaponSchedule`)

술래 시간을 같은 길이로 나눠 단계가 오른다. **다음 단계가 되면 이전 무기는 다시 못 꺼낸다.** 시간이 길수록 단계가 잘게 나뉜다.

| 술래 시간 | 단계 |
| --- | --- |
| 3분 | 🖐️ 맨손 → 🔨 뿅망치 → 🔫 권총 → 🎯 저격총 |
| 5분 | 🖐️ → 🔨 → 🪃 새총 → 🔫 → 🎯 |
| 7분 | 🖐️ → 🔨 → 🪃 → 🔫 → 💥 산탄총 → 🎯 |

| 무기 | 방식 | 사거리 | 간격 | 탄 | 헛친 벌점 |
| --- | --- | --- | --- | --- | --- |
| 🖐️ 맨손 | 앞을 잡는다(부채꼴) | 1.5m | 0.7초 | ∞ | −4 |
| 🔨 뿅망치 | 앞을 친다(넓은 부채꼴) | 2.5m | 0.65초 | ∞ | −6 |
| 🪃 새총 | 조준선 | 16m | 0.8초 | 12 | −6 |
| 🔫 권총 | 조준선 | 32m | 0.45초 | 12 | −8 |
| 💥 산탄총 | 5갈래 | 11m | 1.1초 | 6 | −10 |
| 🎯 저격총 | 조준선 + 확대 조준 | 90m | 1.7초 | 4 | −20 |

- 술래 체력 150 (11-05에 100에서 올림 — 헛손질 몇 번에 너무 빨리 탈락해서).
- **연속 헛손질 가중 (11-06)**: 최근 20초 안에 헛친 횟수 n이면 벌점 × (1 + 0.5n) — 맨손 −4 → −6 → −8… 가끔 하는 실수는 그대로, 근처를 다 두드려 보는 건 손해.
- **잡으면 회복 (11-06)**: 숨은 사람을 잡을 때마다 술래 체력 +25 (최대 150). **숨는 사람이 아닌 것(진짜 물건·NPC·분신)을 치면 벌점만큼 깎이고 0이면 그 라운드 탈락.** 벽·유리를 치면 벌점 없음.
- 숨는 사람은 **한 번 맞으면 바로 잡힌다** ("💥 잡혔다!" + 관전).

## 5. 맵 · 상호작용

- **🚪 문 (E)**: 열고 닫는다(닫히면 막힌다). 현관문·부엌 뒷문·거실 옆문·서재 문은 닫힌 채 시작.
- **🪟 창문 (E)**: 열면 창턱을 점프로 넘어 드나든다(파쿠르). 2층 복도 창문 → 창고 지붕, 다락 지붕창 → 평지붕.
- **⤴️ 점프 (Space)**: 약 1.1m. 마당 울타리를 넘고, 창고 옆 상자 2개를 밟고 창고 지붕까지 오른다.
- **🪜 사다리 (E)**: 아이방 ↔ 다락.
- **🎁 보물 상자 (E)**: 판마다 9곳 중 3곳. 숨는 사람 = 분신 +1, 술래 = 📡 반경 12m 안 숨은 사람 수.
- **🚦 신호등**: 16초 주기(보행 6초). 행인 NPC는 보행 신호를 기다리고, 자동차는 건널목·사람 앞에서 선다.

## 6. 꼼꼼이 모드 (방 옵션)

골목 놀이 **꼼꼬미**(꼼꼼이·꼼꼼아) 규칙을 옮겼다. 원래 놀이: 술래가 전봇대에 눈을 가렸다가 숫자를 세는 대신 정해진 먼 곳을 찍고 돌아오는 동안 숨고, 들킨 사람은 술래보다 먼저 전봇대로 뛰어가 "꼼꼬미!"를 외치며 찍으면 살고, 잡힌 사람이 다음 술래가 된다(지역마다 변형 있음 — 나무위키 "꼼꼬미" 참고).

- **찜 장소 = 술래 기지 전봇대** (사냥 시작부터 열려 있음, 반경 1.3m). 닿으면 "꼼꼬미!" — 탈출 성공 +4점.
- **숨는 시간 비공개**: 술래가 공원 분수·건널목 신호등 등을 찍고 오는 동안 = 20~40초 중 랜덤. 숨는 쪽·술래 화면 모두 시간이 `??:??`, 째깍 소리 없음.
- **"찾는다!"**: 사냥이 시작되는 순간 기지 6m 안(1층)에 있는 숨는 사람은 아웃(우물쭈물하다 들킴).
- **집 지키기 금지**: 술래가 기지 6m 안에 머문 시간이 쌓여 8초가 되면, 그동안 휘두르거나 쏴도 아무도 못 잡는다(벗어나면 2배 속도로 풀림). HUD 경고.
- **승패**: 숨는 쪽 **절반 이상이 꼼꼬미**에 성공해야 숨는 쪽 승(술래가 전멸해도 숨는 쪽 승). 숨기만 하고 버티면 +1점만.
- **다음 술래 = 잡힌 사람**(먼저 잡힌 순). 아무도 안 잡혔으면 술래가 한 번 더, 술래 수가 모자라면 이전 술래로 채움.
- 안 옮긴 것: 본 게임 전 "빈대떡" 노래 면책 미니게임, 등에 그림 찍기 변형.
- 봇: 술래가 전봇대에서 13m 넘게 떨어졌을 때만 꼼꼬미하러 뛴다. 봇끼리(6인 Lv.8, 3분, 8판 32라운드): 술래 승 16 · 숨는 쪽 승 16, 숨는 사람 128명 중 꼼꼬미 51 · 잡힘 71 · 버티기 6, "찾는다!" 아웃 2.

## 9. 구현 메모

- **VRM 캐릭터 (11-06)**: 술래 = 각자 프로필 VRM(방 캐릭터 동기화 `useActiveRoomListing` → `roomCharacterOf`), 행인 NPC·"행인" 변신·그 분신 = 출연진 21명 중 시드·라운드·자리로 고른 VRM(`three/VrmFigure.tsx` `castLook`, 모든 기기가 같은 얼굴). 행인 변신이 자기 VRM이면 술래가 바로 알아봐서 위장이 깨지기 때문(사용자 선택). 점검원·동물·청소기는 저폴리 그대로. 걷기·자세는 한밤의 숨바꼭질 `HouseFigure`를 제자리 드라이브로 재사용.

- **카메라(11-05 후속)**: 배그식 오른쪽 어깨 너머 3인칭. 마우스 입력은 목표 각도에 바로, 실제 시점은 지수 감쇠로 따라가고(조준 중 감도 ½), 피벗은 수평 빠르게·높이 천천히 따라가 계단·점프에서 출렁이지 않는다. 벽에 막히면 즉시 당기고 천천히 풀린다(4갈래 광선). 시야각은 가로 82°(조준 58°, 저격 16°)를 화면 비율에 맞춰 세로로 바꾼다. 캐릭터는 이동 방향으로 부드럽게 돌고, 술래는 조준·공격 직후 카메라 쪽을 본다.
- **화면**: 노을 하늘 돔(셰이더) + 내 주변을 따라다니는 해 그림자(고사양) + 공용 IBL·블룸·비네트(`sceneFx`) + 캔버스로 만든 잔디·아스팔트·보도블록·마루·타일 질감(`three/Atmosphere.tsx`). 저사양은 그림자·후처리 없이 발밑 그림자만.

- **네트워크**: 내 몸 이동은 내 기기가 같은 물리(`physics.ts`)로 바로 계산하고 위치를 보고(10번/초) → 부드럽다. 판정(단계·무기·명중·문·NPC·봇)은 전부 방장 기기(`sim.ts`, 20Hz), 스냅샷 10번/초(`net.ts`)를 받는 쪽이 110ms 늦게 보간. 방장이 순간이동시키면 `tp`를 올려 옛 위치 보고를 버린다.
- **알려진 한계**: 방장이 창을 닫으면 판이 멈춘다(지렁이와 같음). 모든 기기가 모든 사람의 변신 정보를 받으므로 개발자도구로 볼 수 있다(상시 서버 없이는 못 막음). 사람이 나가면 10초 뒤 봇이 이어받는다.
- **충돌**: 벽·바닥·계단 단·가구·지붕이 전부 축 정렬 상자 하나(`Solid`). 발+0.36m보다 높으면 벽, 낮으면 밟고 올라선다 → 계단·파쿠르·지붕이 같은 규칙.
- **봇 (11-06 개편)**: 정답을 보지 않는다. 술래 봇은 사람이 볼 수 있는 단서로만 의심 점수를 매긴다 — 시야에서 움직인 물건 · 아까 비어 있던 칸에 생긴 물건 · 장소에 안 맞는 물건(집 안 소화전 등) · NPC답지 않은 행동(집 안 행인, 뛰는 행인, 점검 안 하는 점검원, 넘어진 물건) · 너무 오래 서 있는 행인/동물. 체력이 깎이고 다음 벌점이 클수록 기준선을 올리고, 헛친 대상은 기억한다. 숨는 봇은 술래 시야(부채꼴+가림)만 보고 굳기/도망/재배치를 정한다. 가중치는 `botParams.ts`, 레벨 1 = 초보값 · 10 = 학습값.
- **셀프플레이 학습 (`selfplay.ts`)**: OpenAI "Emergent Tool Use from Multi-Agent Autocurricula"(2019)의 구조 — 숨는 쪽·찾는 쪽을 번갈아 학습, 상대는 최신 챔피언 80% + 과거 챔피언 20%. 신경망 PPO 대신 파라미터 벡터를 CEM으로(한쪽당 8세대, 후보 12, 후보당 8판). 실행: `MH_TRAIN=1 MH_OUT=out.json npx vitest run src/games/morphHide/selfplay.train.test.ts` (~30분), 측정: `MH_BALANCE=1 … selfplay.balance.test.ts`.
  - 1차 학습에서 술래가 "근처를 다 두드려 보기"(판당 헛손질 22번, 잡힘 70~80%)로 수렴 → 연속 헛손질 가중·잡으면 회복 규칙을 넣고 재학습.
  - 재학습 중 나타난 전략: 2~4세대에 숨는 쪽 전원이 분신을 쓰기 시작(판당 0 → 4개) → 술래가 "새로 생긴 물건" 단서를 버리고(가중치 2.2→0.2) "움직이는 걸 봤다"에 집중 → 숨는 쪽은 멀리 숨어 재배치 없이 버티기.
- **밸런스 (시드 24, 5인 3분)**: Lv10 vs Lv10 잡힘 44% (5분 56%, 4인 40%, 8인 62%), 헛손질 판당 12 (규칙 전 22), 술래 탈락 0%. Lv1 숨기 vs Lv10 술래 79% → 숨는 실력이 승패를 크게 가름. 한계: 강한 숨기(멀리 + 분신 + 안 움직임) 상대로는 학습된 술래도 초보 술래와 비슷(44%) — 관찰만으로는 정지한 물건을 가려낼 단서가 적다.
- **밸런스(봇끼리, 4인 Lv.8, 3분, 꼼꼼이, 12라운드)**: 술래 승 2 · 숨는 쪽 승 10, 찜 탈출 2번, 술래 헛친 횟수 판당 11~20. 사람 술래 기준으로는 아직 미검증.
