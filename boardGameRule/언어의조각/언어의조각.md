# 넷플릭스 《데스게임》 - 언어의 조각 (자모음 조합 변형 / 단판 승부 정식 규칙서)

넷플릭스 예능 《데스게임》의 '언어의 조각'을 개편하여, 공통으로 제공되는 자음/모음 조각들의 조합과 회전(예: 'ㄱ'을 돌려 'ㄴ'으로 변환)을 활용해 단어를 추리하는 **1대1 언어 데스매치** 정식 규칙서입니다.

요청하신 **공통 자모음 조각 부여, 조각 회전 변환 규칙, 글자별 불빛 피드백, 2×N 배열 UI** 조건을 모두 포함하여 단판으로 끝낼 수 있도록 정비되었습니다.

---

## 1. 구성물 및 게임 준비 (Setup)

### 구성물

* **비밀 단어 세팅판 & 가림판 (개인 스크린)**
* **공통 자모음 조각 풀 (Shared Tile Pool):** 두 플레이어가 함께 공유하는 화면 상의 자음/모음 타일 묶음
* **글자별 신호등 불빛 표시기 (글자 수마다 각각 표시):**
* 🔵 **청색불 (Green / 위치 및 글자 완벽 일치):** 해당 위치의 글자가 비밀 단어와 완전히 일치함
* 🟡 **노란불 (Yellow / 포함되나 위치 틀림):** 해당 글자가 비밀 단어에 포함되어 있으나 위치가 다름
* 🔴 **빨간불 (Red / 불일치):** 해당 글자가 비밀 단어에 전혀 포함되어 있지 않음



### 단판 세팅

1. 두 플레이어는 합의된 글자 수(예: 2글자)를 정합니다.
2. 각자 가림판 뒤에서 상대방이 맞혀야 할 비밀 단어(예: **"가을"**)를 설정합니다.
3. **공통 자모음 조각 풀 생성:**
* 정답에 쓰인 자모음과 섞인 무작위 자모음 조각 묶음이 화면 중앙 공통 영역에 표기됩니다.
* *예시 (정답이 "가을"일 때):* **`ㄴ`, `ㅏ`, `ㅇ`, `ㅡ`, `ㄹ**` 형태의 조각 배열이 공통으로 노출됩니다.



---

## 2. 자모음 조합 및 회전 규칙 (Tile Rules)

* **조합 제약:** 초성, 중성, 종성에는 오직 **공통 조각 풀에 존재하는 자모음 및 이들을 회전하여 만들 수 있는 경우의 수**로만 단어를 조합할 수 있습니다.
* **조각 회전 기능:**
* 공통 풀에 있는 조각은 90도/180도 회전시켜 다른 자음/모음으로 변환하여 사용할 수 있습니다.
* *예시:* 풀에 있는 **`ㄴ`** 조각을 돌려 `ㄱ`으로 사용하거나, `ㅡ`를 돌려 `ㅣ`로 활용 가능.



---

## 3. 진행 규칙 및 글자별 불빛 판정 (Turn Rules)

두 플레이어가 번갈아가며 턴을 진행합니다. 자신의 턴이 되면 공통 자모음 조합으로 단어를 만든 뒤 제출합니다.

### 제출 및 글자별 불빛 판정 구조 (1글자 = 1불빛)

단어를 제출하면 전체 1개의 결과가 아닌, **각 글자 칸 밑에 해당하는 불빛이 개별적으로 켜집니다.**

> **[판정 예시] 정답이 "가을" (2글자)인 경우**
> * **플레이어 1이 "을가" 제출 시:**
> * 1번째 글자 ("을") $\rightarrow$ 정답의 2번째 글자 ("을")와 일치하므로 🟡 **노란불**
> * 2번째 글자 ("가") $\rightarrow$ 정답의 1번째 글자 ("가")와 일치하므로 🟡 **노란불**
> * **결과 UI:** `[을 : 🟡]` `[가 : 🟡]` (노란불 2개)
> 
> 
> * **플레이어 2가 "바다" 제출 시:**
> * 1번째 글자 ("바") $\rightarrow$ 정답에 포함되지 않으므로 🔴 **빨간불**
> * 2번째 글자 ("다") $\rightarrow$ 정답에 포함되지 않으므로 🔴 **빨간불**
> * **결과 UI:** `[바 : 🔴]` `[다 : 🔴]` (빨간불 2개)
> 
> 
> 
>

## 4. [화면 UI] 2×N 배열 레이아웃 구조

기존의 플레이어 1, 플레이어 2 기록이 한 줄로 길게 내려가는 형태에서 **화면을 2행 N열(2×N) 격자 배열로 분할**하여 양 플레이어의 기록을 한눈에 비교할 수 있도록 배치합니다.

```text
====================================================================
                       [ 공통 자모음 조각 풀 ]
               [ ㄴ (회전가능), ㅏ, ㅇ, ㅡ, ㄹ ]
====================================================================
 [ 플레이어 1 기록 영역 ]           |  [ 플레이어 2 기록 영역 ]
-----------------------------------+--------------------------------
 1턴: [ 을 | 가 ]                  |  1턴: [ 바 | 다 ]
      [ 🟡 | 🟡 ] (노란불 2개)      |       [ 🔴 | 🔴 ] (빨간불 2개)
-----------------------------------+--------------------------------
 2턴: [ 가 | 을 ]                  |  2턴: [ ... | ... ]
      [ 🔵 | 🔵 ] (모두 맞힘!)      |       [ ... | ... ]
====================================================================

```

## 5. 단판 승부 종료 및 최종 승리 조건

1. **정답 완전 적중 (조기 종료):**
* 제출한 단어의 모든 글자 아래에 🔵 청색불(Green)이 들어온 플레이어가 나오는 즉시 **단판 최종 승리**합니다.


2. **오답 패배:**
* 시도 횟수 제한(예: 5회) 내에 맞히지 못하거나 기권할 경우 즉시 패배합니다.



---

### 💡 핵심 전략 팁

* **조각 회전 수 계산:** 공통 풀의 `ㄴ`을 회전시켜 `ㄱ`으로 썼다면, 정답에 `ㄱ` 형태의 초성이 들어갈 가능성을 염두에 두어야 합니다.
* **글자별 위치 트레이싱:** 글자 단위로 켜지는 노란불을 보고 다음 턴에 1번째 글자와 2번째 글자의 위치를 맞바꿔 제출하는 재빠른 순발력이 승리의 핵심입니다.
